# 发布与报告

实现：`reporting/report.py`、`publication/capabilities.py`、`publication/__init__.py`。

## 单条消息结构

1. 标题：证券、市场、币种、截止时刻、数据版本。
2. 量化结果：按证券一张表，期限 1/5/20/60。
3. 新闻与事件：七档或证据不足，来源、时间、证据范围、链接。
4. 综合摘要：量化与事件是否一致、适用窗口、主要风险。
5. 限制与复现：数据缺口、模型状态、运行 ID、策略哈希。

## 量化表

| 期限 | 绝对上涨概率 | 跑赢基准概率 | 条件收益中位数（10%/90%） | 下行/路径风险 | 验证状态 |
|---|---|---|---|---|---|
| 1/5/20/60 交易日 | 合格值或“不发布（原因）” | 独立判断 | 合格值或“样本不足” | 合格值或缺失原因 | 独立市场/目标状态 |

- 只有 `CapabilityState.VERIFIED` 才显示数值概率。
- 未验证时显示“不发布（未证实优于基准/未执行/数据不足/验证失败）”。
- 基准率单独说明，不等于预测。
- 条件收益缺失写“样本不足”，不填 0。
- 风险可来自历史路径分布，明确“不是未来概率”。

## 特征说明

按组展示：趋势/反转、波动/流动性、价值/质量、说明性指标。缺失因子显示原因。高度相关因子按组解释，不给同义指标重复理由。

## 新闻部分

每项：

- 等级：极大利好/高度利好/中度利好/中性/中度利空/高度利空/极大利空/证据不足。
- 标题、来源、发布时间、证据范围、方法版本、链接。
- 依据（命中词/事实摘要）。
- 事件后价格反应如可得，明确“观察，非因果”。

## 综合摘要

可以说明：

- 量化与事件是否一致或冲突。
- 短期与长期是否相反。
- 高上涨概率是否伴随厚下行尾部。
- 哪些能力已验证、哪些未证实、哪些因数据失败。

不可以：

- 用一句主观判断覆盖“不发布”。
- 把新闻等级换算成概率。
- 输出买卖、仓位、目标价或图表。
- 对未验证模型使用“大概率”“高置信”等表述。

## 降级场景

| 场景 | 仍可交付 | 必须限制 |
|---|---|---|
| 港股行动覆盖未确认 | 已确认窗口描述、当前财务、市场新闻 | 未核实总收益标签及依赖概率 |
| 无同口径基准 | 绝对目标、描述、事件 | 超额概率与纯选股超额 |
| 新闻只有标题 | 事件发现、来源、缺口 | 全文已核实声称 |
| 无历史公开时点 | 当前财务展示、独立价格模型 | 基本面历史训练 |
| 长期限样本不足 | 历史风险、短期限或其他目标 | 长期限精确概率与极端尾部 |
| 网络失败只有旧缓存 | 带日期的描述、其他来源结果 | 最新数据声称、截止后数据混入 |
| 方向模型未证实 | 基准、描述、新闻、独立风险 | 用新闻或 50% 占位的预测 |

## 复现

每次运行保存：

- 请求、策略版本/哈希、代码版本、截止时刻。
- 数据集版本、日历来源、缺失数据集。
- 模型/证据 ID、阶段状态、限制。
- Markdown 和 JSON 输出路径。

`reproduce --run-id` 读取冻结清单并重放 Markdown，不重新训练或用最新数据覆盖。
