# 契约与能力状态

## 契约层次

实现位于 `scripts/stock_research/contracts.py`。模块之间只通过版本化对象交换结果，不读取彼此私有临时文件。

### 请求与身份

- `ResearchRequest`：任务、证券、市场、基准、截止、期限 1/5/20/60、目标、新闻观察窗。
- `SecurityIdentity`：永久证券 ID、有效期 ticker、市场、交易所、类型、币种、上市/退市区间。
- `SessionCalendar`：市场、节假日、提前收盘、覆盖区间与来源。

### 原始证据

- `AcquisitionReceipt`：来源、数据集、子请求、脱敏参数、状态、HTTP、内容类型、字节数、哈希、覆盖、分页/限额、错误。
- `RawManifest`：完整载荷位置与哈希、回执、解析版本、用途和保留政策。

### 规范数据

- `PriceBar`：原始 OHLCV、成交量单位、币种、来源、质量。
- `CorporateAction`：类型、生效日、公开/可得时点、`q`、`cash_old`、确认状态。
- `ActionCoverage`：证券、区间、完整性、证据、未解决项。
- `FinancialFact`：概念、值、单位、期间、fiscal 信息、accession、filed、available。
- `MacroObservation`：序列、统计期、值、单位、发布/可得时点、vintage。
- `DataSnapshot`：一次运行选定的原始清单、规范版本、时点政策、截止和证券范围。

### 特征与实验

- `FactorSpec`：经济假说、组、算法、窗口、方向、最低覆盖、显示/模型用途。
- `FeatureObservation`：因子版本、证券、截止、值、状态、缺失原因、输入依赖。
- `LabelRecord`：目标、期限、进入/结束、收益、基准、label、成熟时间、缺失原因。
- `ExperimentProtocol`：训练/开发/校准/测试块、候选、L2 网格、种子、登记时间。
- `ModelArtifact`：市场、期限、目标、适用范围、因子 schema、变换、系数、校准器、数据集/证据引用。
- `ValidationEvidence`：样本数、独立日期、指标、校准、skill CI、稳定性、状态。
- `CapabilityDecision`：市场、期限、目标、证券、状态、数据层级、原因、模型/证据。
- `RunManifest`：请求、政策、代码、快照、阶段、工件、输出、错误。

## 状态轴不能混用

| 轴 | 状态 |
|---|---|
| 实现 | 仅设计、已实现、已停用 |
| 数据使用 | 不可用、仅上下文、可描述、可用于历史研究 |
| 验证 | 未执行、未证实优势、通过、实验无效、漂移后暂停 |
| 发布 | 发布描述、发布基准、发布已验证结果、不发布 |

“证据不足”是新闻结论状态；“未证实优于基准”是模型证据状态；两者都不是中性值或默认概率。

## 能力判定单位

至少包括：市场、已验证证券范围、输出类型、期限、目标口径、数据/算法/验证版本、有效日期和截止时刻。

示例：

- 缺同口径基准 → 只关闭超额概率。
- 方向模型未证实 → 不删除独立合格的风险描述。
- 港股行动覆盖未验证 → 不发布依赖经济总收益的概率，但保留已确认窗口描述。

## 不变量

- 推理只能使用与训练一致的特征 schema 和变换参数。
- 证据必须属于同一模型、市场、期限和目标。
- 封存预测不可覆盖；修订产生新版本。
- 缺失值带原因，不用零或 50% 占位。
- 一个适配器/子接口失败不能由同一适配器另一个成功结果覆盖。
