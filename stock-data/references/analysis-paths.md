# 专项分析路径

按用户所需维度选择必要数据。普通个股/ETF 分析、简析与“怎么看”统一执行 [新闻工作流](news-first-workflow.md)：默认 60 天，支持 30～60 天，宏观与公司证据并重；有足够新闻时无 OHLCV 也能完成。简析只缩短篇幅。

事实最小查询和完整新闻研究须明确区分。所有影响结论以登记证据为基础，不提供价格预测、技术指标、排名筛选或交易策略入口。

来源以 [来源矩阵](source-matrix.md) 和 request 规划为准。Yahoo 是可选事实背景来源，选择它时遵守 [yfinance-data.md](yfinance-data.md) 的实际来源、限速和 partial 保留规则，不用于填补新闻覆盖。

## 事实与描述性分析

- ticker 已明确时直接使用；公司名称、上市地或证券类型有歧义时，先用当前 Finnhub `search-symbol` 或 global `stock_search` 确认。美股和港股代码转换遵循 [global 来源说明](global-stock-data.md)，不猜东财市场前缀。
- 当前报价通常只取 `get-quote` 或对应 global 行情；历史价格按请求日期和粒度取历史行情。保留行情时间与取数时间，不把历史收盘称为实时价。
- 历史价格只描述实际取得期间的事实，不推演固定期限走势；新闻影响问题转入完整新闻研究流程。

## 基本面与估值

Yahoo gateway 执行需 `--cache-dir runtime/yfinance-cache` 或 `STOCK_DATA_YAHOO_CACHE_DIR`。来源未确认的单位、发布时间和币种保持未知；背景数据不足不妨碍已有充分新闻证据的研究，但必须披露限制。

1. 美股优先 `get-company-profile`、`get-financials-snapshot`；三表、更多关键指标、预期或机构持仓按缺项调用 global 已支持函数。港股按 global 的实际能力取用。
2. 比较前核对币种、金额单位、TTM/年度/季度、会计科目、报告期、披露时间和重述版本。Finnhub 市值的 USD millions 不可直接与其他来源原始金额拼接。SEC 使用 `filed` 判断历史可得性，不用财务期末日替代。
3. 只对实际取得的数据讨论盈利、增长、现金流、负债与估值；指标缺失就保留缺口。高/低 PE 本身不是高估/低估的证明，负盈利或不同口径也不能直接横比。
4. 用户指定比较对象时直接比较；需要发现同行时才用 `get-peers`，选少量代表性同行补取相同口径数据。写明样本选择，不把选中同行当完整行业。

基本面结论只解释可追溯事实与事件承受能力；不生成自动 DCF、目标价或交易建议，也不以这些名称包装主观估算。

## 新闻与公司事件

按 [新闻分析](news-analysis.md) 和 [重大影响规则](news-impact-rubric.md) 执行。新闻、官方公告、观点和传闻分开；事件重发不刷新日期，否认、更正、撤回保存版本与冲突。

- 业绩/指引、订单/客户、产品、融资/债务、分红回购、并购、监管诉讼和管理层：解释对收入、成本、现金流或资本结构的实际影响。
- 宏观：利率/流动性、增长/通胀、汇率、能源/黄金、贸易与行业政策只在实际暴露支持下关联目标。
- “超预期”需要同期预期或此前指引证据；来源观点需发布者与时间，不能代替系统判断。
- 标题可初筛；重大主因需要实质文本和安全原始链接。无法确认时列待核实，不强行中性。
- 唯一重大事件优先 7 天，无合格候选扩至 30 天并明示；仍无候选返回空值。综合结论说明主导原因、相反证据和改变判断条件，不按文章数量投票。

## 多标的比较与综合研究

用户已指定多个标的时，每个 symbol 分别使用独立 request、冻结证据和报告，尽量保持相同截止时间和窗口。可以比较同口径事实及消息传导差异，不生成选股排名或投资组合算法。

一般分析必须读取报告并通过 `validate-report`；未完成时只报告当前事实、状态和缺口，不将报价/财务摘录称完整新闻研究。更深研究按相关业务问题增加已授权原始证据，不机械读取全部来源。

## ETF

先确认 ETF 上市市场、ticker 与资产类型。有足够公告/新闻时无需基金价格历史即可研究；基金持仓、行业和地区敞口须有来源与日期。

按问题补充有来源和日期的跟踪指数、行业、主要成分股与相关新闻；Yahoo `yahoo_funds` 按需读取基金说明/费用/权重/主要持仓，缺持仓日期明示，不回填历史。代码能取得什么就报告什么。没有 NAV、跟踪误差或杠杆信息来源时写明缺口，不假定公司 profile 或 financials 适用于基金，也不以指数/成分股价格替代 ETF OHLCV。

指数或成分股事件只有明确关联该 ETF 的实际主题/敞口时才解释影响。没有暴露证据时仅列背景或缺口，不声称验证了基金特有风险。
