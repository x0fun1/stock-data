# Analysis Paths

按用户所需维度选择必要数据。普通个股/ETF 分析、简析、怎么看及新闻研究统一转入 `SKILL.md` 的新闻流程。**本包不提供未来方向判断或买卖/仓位建议。**

| 请求 | 路径 |
|---|---|
| 报价、历史价格、股票/ETF 资料 | 最小查询；保留实际来源与时间 |
| 基本面、财报、估值 | 描述性分析；事实、指引与推断分开 |
| 新闻、事件、情绪、SEC/IR 披露 | 60 天新闻流程；见 [news-analysis.md](news-analysis.md) |
| 筛选、多标的比较 | 每个标的分别分析，不把单标的结论当横截面模型 |

## 描述性价格统计

- 只报告已经发生的历史趋势、波动和事件窗反应；窗口最多最近 52 周（约 250 个交易日），不得扩大。
- 价格反应只用已经走完的历史窗口；没有成熟窗口时写“无成熟观察窗”。
- `expected_volatility_regime` 只描述波动状态，不含方向。
- 不得把金叉、超买、单一因子 IC 或图形直接换成未来方向结论。

## 交付

- 读取程序生成的 `final_response.md`，实际待发送文本必须通过 `validate-response`。
- 缺失数据标 N/A，证据不足写“证据不足”或“未评估”，不编造。
- 旧 `intent=forecast` / `horizon=5D` 请求返回 `FORECAST_REMOVED`，退出码非 0。
