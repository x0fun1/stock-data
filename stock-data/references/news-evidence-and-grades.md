# 新闻证据与七档结论

实现：`context/news.py`、`acquisition/sources/finnhub.py`、`acquisition/sources/gdelt`（未实现客户端，仅政策）。

## 证据链

1. 发现记录：来源、URL、标题、时间、实体。
2. 许可检查：用途、存储、全文/衍生结果限制。
3. 规范化：实体、事件时间、首次可得时间。
4. 去重：URL、正文哈希、事件聚类三级。
5. 事实提取：只写已证实事实与仍待确认条件。
6. 分级：七档或“证据不足”。
7. 引用：来源、证据定位、可知时间。

转载十次不是十条独立利好。更正与后续进展保留独立版本，不覆盖旧状态。

## 证据范围

| 范围 | 可写 | 不可写 |
|---|---|---|
| 标题/摘要 | 标题级事件、来源、链接 | 已核对公告正文、完整因果 |
| 官方摘录 | 官方事实摘要 | 超出摘录的推断 |
| 全文 | 详细事实、条件 | 未验证的因果或收益 |
| 数值 | 原始数值 | 未核对口径的衍生比率 |

只有标题、目录、索引或日历行时，默认 `证据不足`，不升级为强结论。SEC 8-K 主文件是封面页，事件正文通常在 EX-99.1 等附件；需要单独授权导入。

## 七档方向

| 等级 | 含义 |
|---|---|
| 极大利好 | 重大、明确、范围广的正向事实 |
| 高度利好 | 明确正向，影响较大但非极端 |
| 中度利好 | 有限正向或条件性正向 |
| 中性 | 无方向或信息不足以外的事实性更新 |
| 中度利空 | 有限负向 |
| 高度利空 | 明确负向，影响较大 |
| 极大利空 | 重大、明确、范围广的负向事实 |
| 证据不足 | 无法达到最低证据范围或事实不足 |

等级是文本结论，不是预设收益、数值权重或上涨概率。`grade_event` 的 lexicon 是可解释的占位分类器；方法/版本变化必须重新验证。

## 去重

`canonical_url` 移除 utm/gclid 等追踪参数；`body_hash` 对空白和大小写规范化；`event_cluster` 用于同一事件多来源。重复事件在 `permissions.duplicate_of` 记录主事件 ID。

## 与模型的关系

- 首版新闻 `in_model=False`；报告明确“作为上下文，不调整上述概率”。
- 若未来启用事件因子，创建新因子版本和新模型版本，重新做时点准入、消融、校准和验证。
- 事件后价格变化只记录为观察，不证明因果或已充分定价。
- 港股公告无合格证据时保留缺口，不新增 HKEX 自动采集，不反复索取无法提供的授权材料。
