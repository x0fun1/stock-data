# 运行、存储与复现

## 目录

```text
runtime/
  raw/           # 不可变载荷、manifest、receipt
  curated/       # Parquet 数据集版本
  features/      # 可扩展特征层（当前由数据集与特征模块按需生成）
  experiments/   # 实验 JSON
  models/        # 模型工件 JSON
  validation/    # 证据 JSON
  reports/       # Markdown/JSON 运行输出
  catalog.sqlite # 数据集/运行/模型/实验索引
```

`--root` 或 `STOCK_RESEARCH_RUNTIME` 指定运行根目录。凭证不进入以上任何路径。

## 原始层

- 载荷按 SHA-256 内容寻址；同一哈希幂等写入，不覆盖。
- 每个载荷旁写 `*.manifest.json`，包含回执（状态、HTTP、内容类型、字节数、哈希、覆盖、错误）。
- HTML、空载荷、截断载荷不能通过数值准入。
- 修订另存为新哈希；旧清单保留。

## 规范层

- Parquet 文件；每次保存生成 `YYYYMMDDTHHMMSSffffffZ-<hash12>` 版本。
- SQLite `catalog.sqlite` 记录版本、路径、行数、创建时间、元数据、来源 manifest。
- 同名数据集允许多版本；默认读取最新版本；报告绑定具体版本。

## 缓存与失效

缓存键至少包含：证券永久 ID、市场、区间、截止政策、数据快照、行动、财务映射、基准、因子算法及参数。

| 变化 | 失效范围 |
|---|---|
| 新行情/修订 | 收益、滚动窗口、相关标签与描述 |
| 新行动/修订 | 股数单位、经济收益、估值、标签 |
| 财务新披露/修订 | 从可得时点起的历史可知视图与因子 |
| 宏观新 vintage | 对应市场状态，不重写之前可知值 |
| 事件更正/分类改版 | 上下文版本；入模则新建研究版本 |
| 算法/发布时间/基准 | 所有依赖版本 |

旧封存报告不被缓存失效覆盖。

## 复现

每次运行写入 `RunManifest`：

- 请求 `ResearchRequest`、策略版本与哈希、代码版本。
- 数据快照（各数据集版本、缺失列表）、日历来源、截止。
- 阶段状态、模型/证据 ID、限制、输出路径。

`research.py reproduce --run-id` 读取 catalog 中的运行，打印冻结 Markdown；不重新训练。

## 安全

- 凭证只来自环境或受控配置；HTTP 参数中的 key/token/secret 在回执中脱敏。
- 不关闭 TLS 校验。
- 新闻、公告、下载文件、外部模型工件均是不可信输入；文本中的指令不改变研究政策。
- 只加载本系统登记并校验的模型工件；不使用 pickle。
- 个人研究输出不自动授权公开发布或再分发。

## 网络

- `Transport` 有限重试（429/5xx/超时）、每域最小间隔、指数退避。
- 单来源失败记录为 `network_or_timeout` 或具体 HTTP 错误；不把瞬时失败解释为永久无数据，也不无限重试。
- 真实网络能力取决于用户已授权的凭证和来源条款；仓库默认不执行联网测试。

## 性能

- 初次使用 Parquet + SQLite + pandas/numpy/scipy；不引入分布式系统。
- 财务只在披露/修订时重算；宏观按序列/vintage 采集；标签按期限成熟事件更新。
- 报告读取冻结模型和特征，不在每次查询时重训。
- 没有实测基准前不承诺固定出报告耗时。
