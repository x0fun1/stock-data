# 时间、公司行动与收益口径

## 证据时间

每条数据尽量携带：

- 经济时间：价格交易日、财务期间、宏观统计期、行动生效日。
- 公布时间 `published_at`。
- 首次可得时间 `available_at`。
- 系统接收时间 `received_at`。
- 版本：来源、参数脱敏摘要、单位、复权口径、accession、载荷哈希。

两种历史查询必须区分：

| 查询 | 准入 | 证明 |
|---|---|---|
| 历史可知重建 | 有独立历史发布证据，`available_at` 及处理延迟早于截止 | 值在当时理论上可得 |
| 原运行回放 | 还要求 `received_at` 早于截止 | 该系统当时确实取得 |

只有统计期或结算日、没有发布时点的数据，只能从前向记录开始积累；把日期加一天不是修订问题的通用补丁。

## 原始价与行动

- 保存原始 OHLCV；另建独立行动台账。
- 不使用厂商复权序列作为训练真值。
- `q_t`：每旧股换得的新股数，无拆股为 1。
- `D_old,t`：每旧股现金权益。
- 毛收益增长：`G_t = (q_t*C_t + D_old,t) / C_(t-1)`。
- 自建总收益指数：`J_t = J_(t-1)*G_t`。

供应商按新股计价股息时先转成 `D_old = q * D_new`。拆股兼派息、合股、分拆、供股、特殊分红、并购换股需专门事件；不支持时相关收益明确缺失，不能硬套通用公式。

## 历史特征与估值

在截止 t 内把旧价格转换到同一拆股基准：

```text
C_(u|t) = C_u / product(q_v, u < v <= t)
Volume_(u|t) = Volume_u * product(q_v, u < v <= t)
```

只使用截止时已生效且已知的行动。趋势/动量用 J；财务估值用当时原始价格和当时已知股数，不用 J。成交量先统一“股/手/张”。

## 预测标签

主口径：收盘后发预测，下一当地交易日开盘进入，第 h 个交易日收盘结束。

```text
entry   = next_session(cutoff)
end     = session_offset(entry, h - 1)
R(t,h)  = 从 entry 开盘到 end 收盘、含区间行动的毛总收益
y       = 1{R(t,h) > 0}
y_excess= 1{R(t,h) - R_benchmark(t,h) > 0}
```

规则：

- 开盘日已经除权的现金权益不归当日新进入的参考持有；行动仅对 `ex_date > entry` 生效。
- 缺开盘价、缺收盘价、停牌或路径不完整时标签缺失，不顺延、不补零。
- 退市终值未确认时不凭空结算。
- 同一报告可另列收盘到收盘描述，但不得混入该标签验证。

## 行动覆盖

`action_coverage` 必须显式说明某证券某区间是否已核对。没有覆盖记录表示“未知”，不是“没有行动”。港股缺完整台账时，可单列已确认窗口的原始报价变化，但不能据此发布投资收益概率。
