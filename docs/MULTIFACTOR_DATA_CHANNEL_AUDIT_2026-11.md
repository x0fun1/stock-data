# 多因子信息渠道独立复核 · 2026-11-07

现有来源可以支持美股量价因子和 NVDA 基本面描述。建设七姐妹多因子面板，首先要扩大现有来源的覆盖、规范财务时点及公司行动；历史股票池、历史自由流通股与行业分类、分析师预期、借券和个股期权历史，则存在尚未解决的信息渠道或授权缺口。接口曾返回成功不能证明这些信息已经形成可训练数据。

本次只读核验 SQLite 登记、Parquet、CSV、SEC 完整原载荷与当前源策略，没有读取凭证、调用账户、购买数据或重跑预测。本表是库存状态，不能据此推断今日账户额度。详细旧审计及文件哈希见 [数据渠道机器审计](../runtime/multifactor-integration/data-channel-audit.json)；本次独立复核与其库存数字一致。

## 优先补齐的工作与渠道

| 优先级 | 所需信息 | 现有渠道与缺口 | 解决路径 |
|---|---|---|---|
| P0 | 七姐妹 PIT 财务面板 | SEC 已有 NVDA 完整 facts 与最近 1,000 条申报索引；原载荷另引用 1 个历史索引文件，没有全七股历史验收 | 继续用 SEC，补公司覆盖与历史申报，按 accession 匹配受理时间，保留修订链。初版不必新增财务供应商 |
| P0 | 长公司行动与原始价连续历史 | Tiingo 行动字段已取得，短窗口已保存；长日线尚未经过完整台账验收 | 优先扩展现有 Tiingo 原始载荷，校验拆股比例、股息单位、生效/公布时点、缺失交易日。长历史收益不能直接由原始收盘价 shift 得到 |
| P0 | 历史股票池、证券身份、退市权益 | 当前证券筛选、SEC ticker 和个别退市股探测不等于完整历史股票池 | 需要有效期成分、代码变更及退市处置档案。优先核已授权历史或用户文件；完整无幸存者偏差档案是可能需要补供应商的核心渠道 |
| P0 | 股数/自由流通股、市值、历史行业 | SEC 可提供披露股数和当前粗分类，缺自由流通股及有效期行业 | 先以公开时点股数建立有质量标签的规模估计；自由流通股与行业历史另补授权表或数据档案。GICS/Barra 成品不是唯一选择 |
| P1 | 宏观首发、修订版本与序列定义 | FRED/ALFRED 已有 API 能力，但当前库仅单一 vintage；没有 FX，政策利率映射也未设 | 先明确 RATE 采用目标区间上限、下限或其他口径，并登记真实序列映射；FX 可从现有 FRED 渠道增补已定义的汇率或美元指数。逐次发布重建版本并绑定发布时间，无需先新增供应商；经济观察日期不能替代发布时点 |
| P1 | 分析师一致预期及修正 | Finnhub 账户存在，不代表 EPS/营收预期历史端点和额度已验证；未登记历史预期 | 先核现有权益；不够时补带发布日期、预测财年、版本、分析师数量的授权历史。当前评级快照不能重建预期修正 |
| P1 | 个股期权链/IV 曲面/Greeks/OI | 只有当前延迟链探测；当前源策略未默认启用 CBOE | 需要同口径历史快照和使用资格。VIX 长历史不能代替个股期权历史；可先从基础因子池排除 |
| P1 | 空头余额与借券成本/利用率 | FINRA 双周和 RegSHO 文件有探测值，没有登记历史面板；没有借券费率历史 | FINRA 先补发布日与文件工程；借券费率、可借量、利用率需另外核授权渠道。短卖成交量不等于空头余额 |
| P1 | 新闻正文/事件长期档案 | Finnhub、GDELT、SEC、官方 IR/RSS 有入口；历史正文、首次公开时间与实体去重不足 | 现有来源可继续做背景和事件工程；如加入训练，需要允许使用的长期内容档案和时间证据，不能以抓到 URL 代替正文取得 |
| P2 | 机构持仓/ETF 持仓/真实资金流 | SEC 目录、发行人文件、供应商流量样本没有完整历史解析 | SEC 先补 13F/Form 4/N-PORT 正文和披露滞后；完整日频机构/基金流通常还需授权档案 |
| P2 | 价差、盘口、成交逐笔及成本 | 小时/局部分钟行情不能提供完整报价与冲击历史 | 若后续开展高频研究或准确容量评估，需要另补报价/逐笔/盘口渠道；第一版成本只能使用明确的研究假设 |

P0 限制基础面板构建；P1/P2 是扩展优先级，不代表这些因子加入后必然提高预测。七姐妹同为少数大型科技公司，只有七家公司不能验证普遍的规模溢价或行业中性化。Alphabet 应区分股票类别与公司实体，不把两类股份当两家独立公司；SPY 作为基准，不能当第二家经营公司排名基本面。

本轮另修复了 52/53 周财年匹配：NVDA 的 2026-07-26 应与 2025-07-27 同期比较，不能因周年日相差一天就退回 2025-04-27。资产增长、ROA、ROE、营收 TTM 同比及股数同比已从同一原始公开事实独立复核通过。此项是因子计算修复，未将现有未验收历史升级为训练准入。

现金流和债务口径的后续修复另做了新源代码独立对账：TTM 经营现金流为 1,343.60 亿美元，资本支出 73.54 亿美元，利息费用 4.64 亿美元，长期债务总额 333.66 亿美元。最新季度累计已拆解，新利息标签生效，总长期债务与非流动部分区分。五项流量的共同 TTM 窗口为 2025-07-28—2026-07-26，最新组成事实公开时刻为 2026-08-26 20:36 UTC；营收、净利润和利息与四季求和各相差 100 万美元，差额在工件中保留。同比及相关比率随这个经核对的组件口径更新，旧截图或旧派生值不能作为最终值。

## 可安装 skill 与来源授权

本次复核时，skill 内原生采集客户端为东财、新浪、SEC、FRED、Finnhub；Tiingo、GDELT、HKMA、Census 等名称还存在于策略注册表或旧实验运行脚本中。注册表允许一个来源，并不证明安装后的 skill 已有该来源全部端点、历史分页、原载荷持久化和 PIT 处理。当前公开 CLI 以文件导入消费数据。后续移植应逐端点验收，并以最终代码为准。

模型代码/权重随包分发，与行情、新闻数据的再分发权限是两件事。现有 [`source-policy.json`](../stock-data/policies/source-policy.json) 将东财/新浪数据限定个人研究、禁止再分发；Finnhub 派生结果亦有限制。便携包应继续不含本机凭证或这些运行数据，由安装者使用自己的授权配置或导入文件。策略是项目现有边界，本审计没有重新作法律判断。

本轮发布清单检查使用实际 `build_bundle.py` 和 `install_skill.py` 的选文件规则，源根是 `stock-data/`，本机 `runtime/` 与 `docs/api.txt` 均在该根之外。两套排除规则一致，依赖旧实验目录的 `rolling_baseline.py` 已排除；未发现将被打入包的凭证形状文件或凭证字面量。固定上游源树 92 个文件全部被选择且匹配原哈希，其中保留公共示例 CSV、回归输入/输出、图片与示例预测结果；检查到的 52 项均匹配上游清单哈希。因此这里的排除承诺指本机抓取的运行/训练行情和账户凭证，不能改写为包内完全没有样例数据。

固定依赖的最低 Python 版本为 3.12；本轮对先前独立环境中 42 个同锁版本包的 `Requires-Python` 做了一轮只读核验，全部接受 3.12。完整安装的实际平台证据仍为 Windows x64 / Python 3.13.7 / CPU，元数据核验不是在其他 Python 或平台上重新安装的证据。

港股当前仍缺独立行动台账、公告时间、历史退市池及授权事件/预期渠道。沿用用户此前决定：不从 Yahoo 取港股，不自动抓 HKEXnews。美股工程完成不会自动解决港股渠道缺口。

## 用户补充渠道时最有用的信息

优先补历史股票池/退市权益、有效期股本/自由流通股与行业。每份渠道说明应有来源名、允许的使用范围、证券覆盖、历史起止、更新频率、字段及时间口径。若补预期因子，保留 `security_id`、`available_at`、`forecast_period`、`metric`、`value`、`vintage_id`、`source_id`；如果只有当前快照，请明确标为当前背景。凭证不需要写进聊天或审计报告。

公开工程入口可参考 [SEC 数据 API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)、[FRED 实时版本区间](https://fred.stlouisfed.org/docs/api/fred/realtime_period.html)、[ALFRED 版本库](https://alfred.stlouisfed.org/)、[FINRA 空头余额资料](https://www.finra.org/finra-data/browse-catalog/equity-short-interest)。这些链接说明可选机制，本文库存结论来自上述本地原载荷，而非假定已采集这些链接涵盖的全部历史。
