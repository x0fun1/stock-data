## 结论与口径

来源能连接、载荷含数值、具有完整历史、能按历史可知时点重建、能通过样本外预测验证，是五件不同的事。

此前“45 个适配器拿到真数据，因此拿得到、拿得准”的结论过强，应撤回作为分析就绪度的依据。旧回执可以保留作接口探测记录，不能直接充当训练库。本页和 [量化分析设计](QUANT_ANALYSIS_DESIGN_2026-11.md) 是后续分析的依据，不新增供应商、不改变用户已确认的 US/HK、免费数据和港股禁用 Yahoo 的边界。

本次完成 Census 新密钥接入和带密钥请求。载荷通过列名、数值、地理标识和行数检查，而不只是 HTTP 检查。

## 影响模型设计的证据

- **完整性仍需验收。** 本地新浪 AAPL 与东财未复权日线的对齐存在历史日期缺口，特别是旧年份，不能把行数大视为连续。不得跨缺失交易日直接 shift 出“下一交易日”标签。
- **不能混用旧文件。** `runtime/quant-feasibility/em-kline-us.json` 含负收盘价，是旧复权探测产物。`runtime/probe-20261105/kline/AAPL-fqt0.json` 是不同口径。训练入口必须读取 manifest，而不是按文件名扫描整个 runtime。
- **回执不等于历史库。** 当前 smoke runner 只保留载荷头部，覆盖同名样本，没有完整载荷哈希和逐子接口时间证据。应另建不可变完整快照；这项建设不要求寻找新供应商。
- **部分成功不得扩散成全能力成功。** Tiingo 新闻、Finnhub 港股、iShares、EIA 天然气子请求失败，仍可能有适配器级 `ok=True`。训练准入按子数据集与字段判断。
- **撤回过度归因。** 只见到 FINRA 旧日期的第一页，最多证明现有查询/过滤未验证，不能证明整个 API 永久冻结。某次 SEC 错路径导致 403，也不能证明所有历史 403 都不是限流。EIA 错误页只提示可能受访问或发布窗口限制，不能把所有 403 都当正常缺省。
- **合规不由技术成功改变。** 源授权与字段就绪度分开标记。CBOE 的先授权条款疑点没有因可下载而消失。未经确认的来源可以整体移除，系统必须仍能输出其他维度结果。

证据入口：`runtime/live/sources.py` 中的 `sec_forms`、`fred`、`hk_censtatd`、`etf`、`oecd`；`runtime/live/run_smoke.py` 的回执和样本保存逻辑；`runtime/live/receipts/smoke-r3.jsonl`、`smoke-r4.jsonl`、`smoke-r6.jsonl`。本页基于本地离线核对，除 Census 外没有重新全量调用来源。

## 准入方式

每个字段分别登记：`observed_value`、`full_payload_saved`、`history_validated`、`availability_validated`、`usage_allowed`、`eligible_for_training`。这些标记不与原来源注册表的采用/拒绝评级混为一谈。

- 有值且口径清楚：可做描述分析。
- 历史、价格行动、时间边界通过：可进入回测研究。
- 只有当前状态或时间不清：仅显示上下文，不悄悄加进概率。
- 字段、单位或方向未确认：隔离该项，而不是令其他维度全部失效。
- 完成真正样本外验证与校准：才可以给相应市场、股票范围和期限发布概率。
