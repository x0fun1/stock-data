# 下一小时模型实跑 · 2026-11-07

本文保留原185次、固定180小时输入的历史实验。后续已按用户要求完成全部2,764个目标、每次使用全部既往历史的独立实验，见[全量小时模型测试](FULL_HOURLY_MODEL_TEST_2026-11.md)。两轮结果不混用，原预测不覆盖。

本次已经完成185次小时预测，而非只检查数据能否取得。预测区间2026-09-16至2026-11-05，共37个交易日；每次使用此前180个已完成、无质量缺口的完整小时，目标是同日相邻下一60分钟的收盘是否高于开盘。

| 方法 | 命中/185 | 准确率 |
|---|---:|---:|
| Kronos-small | 98/185 | 52.97% |
| FinCast＋小时量价适配 | 95/185 | 51.35% |
| 纯量价回归对照 | 98/185 | 52.97% |
| 过去180小时上涨率基准 | 107/185 | 57.84% |

两种模型均未达到用户60%门槛，也未超过简单基准。结果不是固定的理论准确率上限；只代表本次窗口、权重、输入信息、目标和时段。

## 实际输入与判断方式

两适配器共用180根开高低收、成交量、估算成交额和纽约时间，原始输入逐条绑定相同哈希。目标小时的真实价格、成交量未进入输入。处理UTC/纽约夏令时，不将隔夜、半小时或缺口当作下一完整小时。

Kronos使用冻结的预训练网络生成16条下一小时K线，按生成开收盘关系判方向。FinCast核心仍是单变量序列；量价适配在每个截止点独立拟合149个同日相邻历史配对，固定ridge=1，再由冻结网络预测180个残差上下文，线性部分与神经残差相加并恢复尺度。窗口首及每天首小时采用历史截距冷启动，不使用跨日训练配对或窗口外lag。

网络权重未微调，宏观、新闻、财务、大盘与行业信息未输入模型。FinCast辅助回归的系数随着近期窗口变化，这不是对991M神经网络进行持续训练。

## 数据增长与理论限制

存入更多历史文件不等于模型学过这些数据。固定180小时窗口时，窗口外记录不进入当前推理。扩大上下文、增加训练样本和更新网络是不同实验；可能改善适配，也可能因过时规律、噪声或不合适特征而无改善或下降。

固定信息集存在未知的最优可达分类准确率，但不能从185次成绩判断已经达到该上限。市场关系和可用信息也会变化。下一步若研究数据量效果，应在事前固定的评估日期上分别比较上下文长度、训练窗口或微调方案，不反复调整同一测试段直到60%。

宏观政策应进入完整研究与风险解释；要参与数字预测，必须显式编码预测时已公开的政策、市场/利率状态、事件日历或发布后的意外值，并重新验证。量价包含部分已发生事件反应，但不能替代未来未公布政策信息。

## 验证与证据

185小时不是185个独立交易日。本次按37日期成组检查及重采样；区间只反映已封存评分，不包括网络重训或全部随机路径生成不确定性。Kronos部分生成路径违反高低价排序，已保留记录，不能作为可靠极值风险模拟。
