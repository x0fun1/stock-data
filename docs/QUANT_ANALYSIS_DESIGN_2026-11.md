# 多因子量化分析与概率评估设计 · 2026-11-06

## 1. 设计结论与范围

目标不是汇总尽可能多的指标，也不是给每只股票强行生成一个分数，而是构建可核对的链路：

**历史可知数据 → 少量有经济含义的因子 → 时间顺序的样本外实验 → 概率校准与风险分布 → 带适用范围的研究结果。**

本设计回答现有数据支持什么分析、指标算法、统一信号、权重、不同期限概率、验证、防过拟合、计算效率与最终交付。它是建设规格，不是已经训练完成或具有确定预测优势的模型。尚无可发布的已验证上涨概率。

边界保持不变：US/HK、免费数据、个人研究、一个统一研究系统，不做交易执行、仓位配置或图表。继续使用用户确认的东财/新浪/腾讯和已提供的密钥；港股不取 Yahoo，不重新要求用户提供无法提供的授权材料。

### 1.1 三层产物必须分开

| 层次 | 可以回答 | 不能冒充 |
|---|---|---|
| 描述性统计 | 现在处于什么趋势、波动、估值、财务和事件状态 | 已被验证的未来收益预测 |
| 历史解释与因子检验 | 过去哪些特征与未来收益有关，条件分组差异有多大 | 因果关系或未来必然重复 |
| 样本外概率与风险 | 在明确数据范围和期限下，模型概率是否校准、是否优于基准 | 保证收益、万能准确率 |

优先建立美股日频价格/风险核心、SEC 历史可知基本面和宏观版本库。港股仍保留独立分析支线，但缺少行动台账或公告时点的能力不能照搬美股模型。新闻、期权及部分持仓先进入上下文，只有补齐历史可知证据后才参与训练。这是按能力分层，不是把 US/HK 需求缩成只做美股。

来源级的 smoke 成功并不代表训练就绪，具体更正见 [数据就绪度核对](ANALYSIS_DATA_READINESS_2026-11.md)。Census 新密钥已验证人口估计查询，但人口快照不会自动成为短期股价因子。

### 1.2 模型目标

| 目标 | 定义 | 用途 |
|---|---|---|
| 绝对上涨概率 | 未来约定区间的总收益大于零 | 方向参考 |
| 跑赢基准概率 | 同期总收益超过同币种、同市场基准 | 区分市场普涨和个股相对强弱 |
| 条件收益分布 | 未来总收益的中位数、分位数与尾部 | 风险回报而非只看胜率 |
| 路径风险 | 期限内最差浮动损失、峰谷回撤或首次触及阈值 | 与期末涨跌不同，单独建标签 |

初版期限固定为交易日，不进行自动海量搜参：

| h | 含义 | 主要注意点 |
|---|---|---|
| 1 | 下一交易时段 | 噪声和微观结构影响很大，允许无预测优势 |
| 5 | 约一周 | 短期反转、量价和波动状态 |
| 20 | 约一月 | 趋势、质量、宏观风险 |
| 60 | 约一季 | 独立样本少，基本面和环境更重要，区间通常更宽 |

不预设长周期上涨概率比短周期大，不把日概率乘 h，也不使用 `1-(1-p)^h` 推导区间上涨概率。它们不是独立的每日上涨事件。

## 2. 先定义时间与收益，后计算指标

### 2.1 每条数据必须具备的证据字段

- 身份：永久证券 ID、当时 ticker、市场、证券类型、币种、交易所、上市/退市状态。
- 经济时间：价格所属交易日、财报所属期间、宏观统计期、公司行动生效日。
- 可知时间：公开发布时间 `published_at`，有证据的首次可得时间 `available_at`，本系统收到时间 `received_at`。
- 版本：来源、接口、查询参数脱敏摘要、单位、复权口径、版本/修订号、accession、完整载荷哈希。
- 质量：缺失原因、来源分歧、是否估算发布时间、是否只有日期、是否能入训练。

模型特征必须满足 `available_at <= prediction_cutoff`，并考虑实际处理延迟。实时评估还要满足 `received_at <= prediction_cutoff`。今天回补历史时，只有存在独立的历史发布证据，才能模拟当时可知；否则只能从本次前向记录开始。

`report_end`、宏观 observation date、FINRA settlement date 都不是公开时间。今天最新修订值不能无条件回填过去。只知道公开日期时，默认从下一当地交易日使用；日期字段可靠性仍须验证，不把保守加一天当成修订问题的万能补丁。

默认每日收盘后固定截止时刻生成特征，但任何当天尚未送达的价格、新闻、宏观或公告不得进入。截止时刻按市场与供应商延迟配置；避免用“收盘已过”假设所有收盘数据都已到。

### 2.2 原始价与公司行动

禁止使用供应商复权序列作为训练输入真值。保存原始 OHLCV，另建带生效日期与可知日期的行动台账。

统一记号：`C_t` 为原始收盘价，`q_t` 为每旧股换得的新股数，无拆股时为 1；`D_old,t` 为每旧股对应的现金权益。简单拆股/现金股息情况下：

```text
G_t = (q_t * C_t + D_old,t) / C_(t-1)
R_t = G_t - 1
r_t = log(G_t)
J_t = J_(t-1) * G_t
```

`J` 是系统自行重建的毛总收益指数，假定股息在除权日收盘按该价再投资，不含税费。若供应商股息是按新股计，则先转换为 `D_old = q * D_new`。不能在不了解单位时把 `divCash` 直接套入任何公式。拆股兼派息、合股、分拆、供股、特殊分红、并购换股需要专门事件处理，不能由通用公式硬算。

原始成交量也要核清“股/手/张”。比较拆股前后成交量时转为同一股数基准；成交金额优先保留原始价乘原始成交股数，不能将未复权价格乘厂商复权成交量。

在历史截止 t 内将旧价格转换到同一拆股单位：

```text
C_(u|t) = C_u / product(q_v, u < v <= t)
Volume_(u|t) = Volume_u * product(q_v, u < v <= t)
```

只允许使用截至 t 已生效的行动。趋势/动量优先用 J，以避免现金分红制造假跌幅。财务估值使用当时原始价格与当时股数，不用 J。

港股没有完整行动台账时，未识别公司行动前后的经济收益可能错误。不能仅删掉“大跌日”解决，因为真实崩盘也会被删掉。可报告已确认窗口的描述统计；无法验证的历史标签标为缺失，暂停该能力的概率发布。原始报价变化可以单列，但必须明确不等于投资总收益。

### 2.3 明确的预测标签

主研究口径是收盘后发出预测，以下一交易日开盘为基准，以第 h 个交易日收盘为终点：

```text
prediction_cutoff: t 日收盘后指定时刻
reference_start: 下一当地交易日开盘 O_(t+1)
reference_end: 第 h 个交易日收盘 C_(t+h)
R_(t,h): 这段持有区间的毛总收益，含区间内适用的行动
y_(t,h) = 1{R_(t,h) > 0}
y_excess_(t,h) = 1{R_(t,h) - R_benchmark_(t,h) > 0}
```

用一份持股/现金权益模拟器计算含行动的区间收益。不能把前一天收盘开始的总收益指数比值直接当成下一开盘买入收益。开盘日已除权的现金权益不归该日新进入的参考持仓。停牌、没有可用开盘价、退市结算未确认时，该标签不能凭空补零或移到一个方便的日期。

这是预测结果的统一衡量口径，不是交易执行策略。同一报告可以另列收盘到收盘的历史描述，但不得混进该标签的验证。

收益、基准和税费口径必须一致。若港股基准只有恒指价格指数，不能把个股含息收益与它的价格收益差称为纯选股超额。基准相应缺失时不输出超额概率，而保留其他结果。

## 3. 维度与算法目录

所有窗口、方向和变换在实验开始前登记。下列是有限候选集，不是全部自动进入模型。数据缺失不补成中性，显示指标不一定参与预测。

### 3.1 量价、趋势、风险与流动性

以下 `J` 为自建总收益指数，`R` 为简单总收益，`r` 为对数总收益；`sigma_w` 为过去 w 个有效日的 r 标准差。金额在市场内保持统一币种。

| 因子/指标 | 默认算法 | 解释与取舍 |
|---|---|---|
| 中期动量 MOM60 | `log(J_t/J_(t-60))` | 趋势持续候选，不预设总是正效应 |
| 跳月长期动量 MOM12_1 | `log(J_(t-21)/J_(t-252))` | 将近月反转与较长期动量区分；需足够历史 |
| 平滑趋势差 | `log(EMA20(J)/EMA60(J))/sigma60` | EMA 的 alpha=`2/(n+1)`；是无量纲状态值，不是统计显著性 |
| 短期残差反转 | `-sum(epsilon_(t-4:t))/(std60(epsilon)*sqrt(5))` | epsilon 来自只用过去数据拟合的个股对基准回归；短期反转不与长期动量混为一项 |
| 相对强弱 | 过去 60 日个股累计总收益减同区间基准累计总收益 | 与残差动量高度重复时二选一；跨股比较基准一致 |
| 实现波动率 RV20 | `std(r_(t-19:t), ddof=1)*sqrt(A_market)` | A 为明确的年化交易日约定；年化只用于显示，不自动推出多期概率 |
| 波动变化 | `sigma20/sigma60-1` | 收缩/扩张状态，不天然等于涨跌方向 |
| 下行波动 | `sqrt(A*mean(min(R,0)^2))` | 使用全部有效日作分母；与只对负日取标准差不同 |
| 当前回撤 DD60 | `J_t/max(J_(t-59:t))-1` | 当前位置离近期高点的距离；不等于窗口最大回撤 |
| 历史最大回撤 | 窗口内运行峰值计算 `min(J_v/running_max(J)_v-1)` | 区分历史风险和未来预测路径风险 |
| 异常成交量 | `log(V_same_basis,t / median(V_same_basis,t-20:t-1))` | 使用过去 20 日基线；必须先统一拆股与股/手单位 |
| 成交量惊喜 | 上述量的滚动 MAD 标准化 | 与异常成交量二选一，不双重计票 |
| Amihud 非流动性 | `mean20(abs(R_t)/Amount_t)` | Amount>0；小额成交会放大噪声；各市场/币种内标准化 |
| 市场 beta | 过去 252 日个股超额收益对市场超额收益回归的斜率 | 历史风险暴露，不是上涨预测本身；无完整窗口可用预设较短窗并标注 |
| 特异波动 | 上述回归残差标准差年化 | 与总波动分开，避免只挑市场高 beta 股 |
| 市场广度 | 历史可用股票池中 `J > SMA60(J)` 的比例 | 仅在历史股票池已验证后启用，不能用今日成分股重建过去广度 |

波动为零、分母为零、低成交或窗口不足应产生明确缺失状态。不能输出无穷大后依赖 winsorization 掩盖问题。

技术指标作为说明性显示而非首批重复因子：

| 指标 | 计算 | 为什么不默认再加一票 |
|---|---|---|
| RSI14 | Wilder 平滑上涨量/下跌量，`100-100/(1+RS)`；首期使用 14 日均值初始化 | 与短期动量/反转重叠；RSI>70 不自动代表应跌 |
| MACD | `EMA12-EMA26`，信号线 EMA9，柱线为二者差 | 与平滑趋势差重叠；柱线是否乘 2 只影响显示约定 |
| 布林位置 | `(J-SMA20(J))/std20(J)` | 本质是标准化均线偏离，不与该类信号重复加入 |
| ATR14% | Wilder 平滑 `max(H-L,abs(H-Cprev),abs(L-Cprev))/C` | OHLC 和 Cprev 先转到同一行动单位；反映区间风险，不直接投方向票 |

初版价格模型建议只保留以下候选，经训练内去相关再减少：MOM60、MOM12_1、趋势差、残差反转、RV20、波动变化、DD60、异常成交量、Amihud、beta、特异波动。先跑单组等权与小模型基线，不靠大量同义指标取得表面“共识”。

### 3.2 基本面

SEC 首先生成历史可知的标准财务表，再计算比率。金额币种、期间长度、合并范围与分母定义保持一致。季度累计值需要拆解：单季 Q2=H1-Q1；Q3=9M-H1；Q4=FY-9M。每次相减必须使用截至该时点可知且口径兼容的版本，不能混用未来修订。

TTM 使用最近四个不重叠有效季度。处理 52/53 周财年、财年变更、拆股后的 EPS 口径和 XBRL 扩展标签，禁止直接按相同中文字段名拼接。

| 维度/因子 | 算法 | 使用约束 |
|---|---|---|
| 盈利收益率 E/P | `NetIncome_TTM/MarketCap_asof` | 保留负盈利含义；不对负利润公司使用“低 PE 就便宜”的排序 |
| 自由现金流收益率 | `(CFO_TTM-Capex_TTM)/MarketCap_asof` | Capex 先统一支出为正的符号；金融行业不强套通用 Capex 模型 |
| 盈利质量 ROA | `NetIncome_TTM/avg(Assets_now,Assets_1y_ago)` | 资产均值来自历史可知报表 |
| 应计项质量 | `-(NetIncome_TTM-CFO_TTM)/avg_Assets` | 负号仅为便于解释“高值=现金支持较强”；预测效应仍需验证 |
| 毛利率及改善 | `GrossProfit_TTM/Revenue_TTM`；同比差 | 银行/保险未必具有可比毛利概念，按行业模板或缺失处理 |
| 营收增长 | 正基数用 `Revenue_TTM/Revenue_TTM_1yago-1` | 基数非正、零或会计期间异常时不算无限增长 |
| 利润改善 | `(NI_TTM-NI_TTM_1yago)/avg_Assets` | 比利润百分比增长更能处理盈亏切换 |
| 财务杠杆 | `TotalDebt/Assets` | 必须定义有息债，不把总负债默认当债务 |
| 净负债 | `(TotalDebt-Cash)/Assets` | 净现金可为负，不能截成零 |
| 利息保障 | `EBIT_TTM/InterestExpense_TTM` | 分母为零、资本化利息等需分开处理；不作为通用跨行业默认因子 |
| 股数变化 | `Shares_now/Shares_1yago-1` | 先剔除拆股影响；回购/稀释描述，不能混用加权平均股数和期末股数 |

首批基本面候选优先 E/P、自由现金流收益率、ROA、应计项、营收增长、净负债。市值必须由对应时点价格和已知股数重建，不能把今天市值套过去。SEC filings 的当时更新记录有可用性，但“filed 日期 + 最新值”不是完整的 point-in-time 实现。

有历史行业分类时做行业内标准化或回归中性化。没有时不借今日行业做历史精细中性化；改用可验证的粗分组/不做，并记录行业暴露。香港无公告时点的 F10 仅用于当前基本面展示，不进历史模型。

### 3.3 宏观、市场风险和事件

宏观因子主要解释共同市场状态，不应因为同一天有很多股票就当成很多独立宏观观测。美股和港股采用不同市场日历与截止时刻。

| 候选项 | 算法 | 时点/能力限制 |
|---|---|---|
| 收益率曲线 | `y10y-y2y`；预设窗口的变化 | 两条收益率均须在 cutoff 前已公布；单位统一百分点 |
| 政策/融资变化 | 可得 SOFR/EFFR/政策利率的 20 日或上次发布差 | 只在已知更新时变化，不从统计期起点向前填 |
| 通胀及变化 | `100*(CPI_t/CPI_(t-12)-1)`；同比率的差 | 使用截至当时已发布的 vintage；不是取今天修订后的整条序列 |
| 就业/活动改善 | 失业金 4 周均值及其同比/变化，或已获得的同类序列 | 由真实发布批次计算；不能当作每天一个新样本 |
| 波动环境 | 合规准入后，VIX 水平/滚动分位；或已验证的基准实现波动 | 未获准的指数源不用；替代字段需要独立模型版本，不临时换公式 |
| 波动期限斜率 | `VIX3M/VIX-1` | 代表隐含风险结构，不是实体概率；数据资格独立判断 |
| 汇率压力 | `log(FX_t/FX_(t-20))` | 固定报价方向和币种；HKD 联系汇率区间下的解释不同于自由浮动货币 |
| 商品风险变化 | 已验证原油等序列的 20 日变化或标准化冲击 | 与行业实际暴露连接；当前只有 XLS 文件头不构成可训练序列 |
| Census 经济指标 | 指定月度序列的同比、环比和版本变动 | 尚未验证这些具体序列；本次人口样本只做背景，不造“高频增长因子” |

没有当时分析师一致预期时，不能将“本期值减上期值”命名为经济数据/财报惊喜。

事件类的算法可以先规定，但必须等数据满足准入，不能先编一个值：

| 因子 | 算法 | 不可忽略的限制 |
|---|---|---|
| 盈利变化型 SUE | `(EPS_q-EPS_(q-4))/std(EPS_k-EPS_(k-4), 过去8个可得季度)` | 这是季节性历史基准，不是分析师预期惊喜；EPS 先统一股本口径 |
| 分析师预期惊喜 | `(Actual-Consensus_pre_release)/scale` | 没有公告前冻结的一致预期时不启用；当前日历不证明该数据可用 |
| 公告后漂移 | 用公告后已过去窗口的异常收益作特征，预测更晚的窗口 | 不能用公告后 CAR 预测同一段公告后收益；财报当日含盘前/盘后差异 |
| 内部人净买入 | 只统计匹配交易代码的公开市场 P/S，金额按市值或流动性缩放 | Form 4 目录还不是正文。排除授予、税务扣缴等不同性质交易；按披露时点使用 |
| 13F 持仓变化 | 同机构/同证券的两期可比持仓变化 | 仅在报告公开后可用；13F 不是实时全仓、不含所有空头；当前未实现该正文采集 |
| Short interest/DTC | `short_shares/可得float`；或 `short_shares/同口径平均成交量` | 无可靠历史流通股时不算 short/float；按公开日而非结算日进入 |
| RegSHO 比例 | `ShortVolume/TotalVolume` | 仅限该申报文件覆盖的设施与成交范围，不解读为全市场净做空 |
| 新闻事件强度 | 同一事件去重后，按相关性和时间衰减聚合数量/新颖度 | 转发十次不是十条独立利好。无法证明历史可知/去重前只作背景 |

新闻输出仍沿用用户决定的七档方向标签及独立“证据不足”。标签是文本结论，不是预先设定的数值收益。若未来有满足时点要求的历史标签，可作为类别变量和事件类型与价格模型联测；当前不把“高度利好”硬换成“上涨概率 80%”。新闻分类方法或版本改变，也必须重新验证。

当前期权的隐含波动、期限结构、价差/流动性等可以作风险背景。隐含分布通常是风险中性分布，不是实际世界上涨概率，不能用 N(d2) 直接替代经历史校准的方向概率。缺少历史期权链时，不给模型暗中增加实时期权打分。

## 4. 多个指标如何变成统一信号

### 4.1 清洗与归一化

1. 先校验语义、单位和可知时间，再处理异常值。明显数据错误应隔离，真实极端风险日必须保留。
2. 连续特征可采用训练段拟合的 winsorization 和稳健标准化。默认候选：分位裁剪 1%/99%，或中位数/MAD 标准化后裁剪到 [-3,3]；不要无必要叠加多套裁剪。
3. `z=(x-median)/(1.4826*MAD)`。MAD 为零时按预登记顺序换训练段 IQR/标准差；仍为零则停用常数列。归一化参数只在训练段拟合。
4. 截面选股可采用同一时点可知股票池的 rank 分位。此时没有使用未来标签，但它预测的是相对位置，不应与单股的时间序列 z 混为一谈。
5. 同一数据集只能采用预先选定的主归一化方式。不能看到结果不好就随意在 rank/z/原值之间挑最有利者。
6. 缺失数值不直接填零。训练内中位数填充要伴随缺失指示、数据年龄和范围限制；严重缺失时使用独立验证的缺少该维度的模型，或暂停该项预测。

### 4.2 从因子到组，再到输出

先按经济含义分组：趋势/反转、波动与流动性、价值、质量与增长、市场宏观、合格事件。风险因子并非都应有“越大越看涨”的方向。

最简单的研究基线：训练内统一方向和归一化后组内等权、组间等权。权重和方向必须提前指定或只在训练段决定。不把指标数量多的组自然变成高权重。

**展示分数与概率分离：**

- 展示用相对分数可以是训练基准分布下的百分位 0–100，并解释参考范围。
- 70 分不等于 70% 上涨概率；分数高也不等于风险低。
- 尚无验证权重时不发布带强方向含义的“综合买卖分”。先显示分维度状态。
- 合成模型只用已通过该版本数据准入的特征。背景信息必须单列，不能悄悄调整模型概率。

### 4.3 首选模型

方向概率先用正则化逻辑回归，收益中位数/分位数用正则化线性或分位数回归。解释性强、参数少，是评估复杂模型是否真的有价值的参照。

```text
eta_(i,t,h) = b_(market,h) + sum_j beta_(j,h) * z_(i,t,j)
p_raw_(i,t,h) = sigmoid(eta_(i,t,h))
loss = weighted_log_loss + lambda1*||beta||_1 + lambda2*||beta||_2^2
```

默认从 L2 开始，仅在内层验证证明有益时引入 Elastic Net。每个市场、期限独立验证。多股样本按日期分组切分，训练可给每个日期相近总权重，避免股票多的日期主导；报告同时给等日与等样本结果。

不为了类别平衡而随意重采样涨跌。类别权重会改变后验概率，需要恢复目标分布并重新校准。训练权重应有明确的研究目标，而不是仅追求更高准确率。

有证据证明交互作用带来稳定增益后，才比较浅层、有限叶数、早停的梯度提升树。复杂度、参数预算、尝试次数预登记。随机森林、神经网络、LSTM/Transformer 不作为初版必需组件。

## 5. 指标是否有效、相关性与权重

### 5.1 有效性不是只看相关系数

每个“因子 × 市场 × 期限”建立检验卡：

| 证据 | 方法 | 必须避免 |
|---|---|---|
| 经济理由 | 明确趋势、风险补偿、估值或信息扩散假说 | 先扫出结果再编理由 |
| Rank IC | 截面 Spearman(feature_t, future_return_h) | 把所有股票日期混在一起算一次相关 |
| IC 稳定性 | 按日期计算 IC，报告均值、中位数、正值比例和分阶段表现 | 只报最优一年的均值 |
| 单股时间关系 | 在时间块内检验特征与未来收益，使用块重采样 | 单股 IC 和多股截面 IC 混称同一指标 |
| 分位组 | 每日形成因子分位组，比较未来收益、风险和单调性 | 用测试期未来表现反过来挑分位阈值 |
| 条件分组 | 牛/熊、高/低波动、流动性等当时可识别状态 | 用全样本事后“顶/底”定义实时状态 |
| 增量价值 | 去掉/加入整组因子的样本外 Brier、log loss、收益分位损失变化 | 单独有效就假定在已有模型里也有效 |
| 实务稳定性 | 缺失率、周转、陈旧度、来源差异和可获得时间 | 只保留数值上最强但不可持续获取的因子 |

IC 的标准误使用适合依赖序列的 HAC 或时间块 bootstrap，滞后长度至少考虑 h-1 的重叠标签并对更长自相关作敏感性分析。`mean(IC)/std(IC)` 本身不等于显著性或通用年化 ICIR。

因子正负方向不跨期限强行固定。五日反转与六十日趋势可能方向相反，这不自动是模型矛盾。

### 5.2 控制重复与相关性

只在训练段计算 Pearson 与 Spearman 相关矩阵，也检查缺失共同性和来源共同性。对 |rho| 高的因子做经济分组和相关聚类，默认高相关告警线可以先登记为 0.8，再检验邻近阈值的稳定性，不把它当自然定律。

- 同一变换族优先选一项代表，例如 MACD、均线差、趋势斜率不能各算一次独立证据。
- 候选代表的取舍按数据质量、稳定性和验证增量，而非全历史最优 IC。
- 若保留相关特征，采用正则化或训练内残差化；残差化顺序也需要登记。
- 评价重要性时按组做时间块置换或消融。独立乱序会破坏时序；高度相关特征的单变量重要性容易失真。
- 主成分分析仅为可选压缩，不自动创造经济含义或预测有效性，也只能在训练段拟合。

### 5.3 权重怎么产生

分三层比较，不直接指定“技术 40%、基本面 30%”作为最终权重：

1. 无预测优势假设的基准和组间等权基线。
2. 各期限正则化模型在训练段学习的系数，超参数只由内层时间验证确定。
3. 若组合多个已验证模型，使用非负、和为 1、带收缩的组合权重，通过内层样本外损失拟合，最终测试不参与选权。

不能简单用 `权重 ∝ abs(IC)`，因为它忽略误差、共线性、非平稳性和重复因子。也不能在概率掉准时临时手工改权。

权重按预登记周期重估，例如每季度，校准器和数据版本独立记录。早期不引入自动每日追涨式调权。若使用指数衰减训练权重，半衰期也是训练内超参数，必须与不衰减基准比较。

所有尝试必须入实验台账，包括未采用的窗口、因子与模型。探索阶段多重检验按因子族/期限控制错误发现率，并结合依赖性选用适当方法；最终仍依赖真正前向留出的验证，不能用一张显著性表替代。

## 6. 不同期限的上涨概率与风险分布

### 6.1 独立概率校准

每个 h 都有自己的标签、模型、校准器和指标。对严格不参与该模型训练和选参的后续校准块，用 sigmoid/Platt 校准：

```text
p_cal = sigmoid(a_h + b_h * logit(p_raw))
```

`p_raw` 做数值裁剪，防止 logit 溢出。也可直接校准逻辑回归的原始决策值。是否限制斜率、是否校准均由开发验证确定。

小样本优先简单 sigmoid，不能因为某次拟合更好就选自由度高的 isotonic。官方文档提示 isotonic 在小样本更易过拟合；金融重叠观测下，即使有很多行也不代表拥有相同数量的独立样本。

校准数据不能重复拿来选模型，也不能把最终测试的真实涨跌用于校准该次测试的预测。后续在线校准只允许使用已经成熟的历史标签。

概率输出至少带：期限、区间参考价定义、绝对/超额口径、市场范围、数据截止、验证版本和有效样本证据。没有验证支持就输出“尚未建立可靠概率”，不填 50%。

### 6.2 收益与下行风险

首版给出条件收益中位数及 10%/90% 分位，可由分位数回归估计：

```text
rho_tau(u) = u * (tau - 1{u < 0})
min_theta sum rho_tau(R_(t,h) - f_theta(x_t)) + regularization
```

分位交叉需要校正，校正方法和覆盖率仍须在样本外验证。也可用训练期相似状态的历史区块作有限样本基线，但必须显示有效样本量与适用范围，不把最近邻历史频率当稳健概率保证。

若有可靠的完整条件收益分布，可定义：

```text
loss L = -R
VaR_alpha = quantile_alpha(L)
ES_alpha = E[L | L >= VaR_alpha]   # 离散样本需约定分位处权重
P_loss_d = P(R < -d)
```

尾部样本不足时不发布精确 ES，尤其不能从少量月度/季度独立窗口硬估 99% 尾部。可先展示历史压力期实际表现和当前风险暴露。极端风险数据错误要清理，真实极端收益不能裁掉后再计算尾部风险。

终点收益分位不描述中间路径。期限内跌破某阈值、最大回撤、最差浮动损失需要由逐日持有路径另建标签，单独验证。日收盘路径与含盘中低点路径也不同，不假装前者覆盖了盘中风险。

### 6.3 三种不确定性不能混用

- **收益预测区间**：未来一次结果本身可能出现多大波动。
- **概率估计不确定性**：模型/校准的抽样误差，使用按日期块重采样并重新拟合整条流程评估。
- **数据/分布风险**：缺字段、发布时延、模型没见过的市场状态，不会被一个窄统计区间自动覆盖。

当前信号方向、预期收益和风险可以不一致，例如上涨概率较高但下跌尾部很厚。输出必须允许这种结果，不能把高胜率写成低风险。

标准正态假设和平方根时间缩放可以作为简化基线，但不作为最终多期概率真值。传统 conformal prediction 的无条件覆盖保证依赖交换性等条件，金融序列通常不满足；若采用滚动/分块修正也需报告实测覆盖，不能宣称天然有严格保证。

## 7. 如何验证准确性、稳定性与可靠性

### 7.1 时间顺序的嵌套验证

采用滚动或扩展训练窗。先固定实验协议，再查看结果：

```text
训练块：清洗参数、财务映射规则版本、特征变换、相关聚类、模型拟合
后续开发验证块：选有限超参数、候选组和复杂度
再后续校准块：拟合概率校准，不参与选参
再后续测试块：冻结全部流程，记录未见过样本的预测
沿时间前推，重复得到真正样本外预测带
最末封存区间：研发期间不查看，最终审查只使用一次
```

数据允许时，起始训练可用至少五年作为候选，开发验证和校准各保留后续整段，测试以半年或一年滚动。它们是工程起点而非足够样本的证明。60 日预测尤其不能拿一年中的约四个不重叠季度窗口宣称校准可靠；须增加历史跨度、积累前向样本或限制发布。

不反复查看封存测试直到模型变好。数据已被研发者用来设计规则的区间，应标为开发数据；真正前向留出能力只能随新数据逐渐积累。对留出集的每一次审查也记录在实验台账。

### 7.2 重叠标签、purge 与 embargo

每个样本保存特征截止、标签开始和标签结束时间。训练样本的标签区间不得跨入用于选参、校准或测试的后续区间。所有同日股票放在同一分区。

- 不能随机拆分行，也不能把某股票的未来日期训练给另一股票的过去日期测试。
- 对预测窗口 h，删除边界前标签未成熟或与留出标签重叠的训练样本。统一多期限流程可用最大 h 的保守缓冲，但最终检查依赖真实日历与区间，不依赖固定行数。
- 纯向前 walk-forward 不使用测试之后的数据训练同一折；仍需要边界 purge。采用会使用后段数据的额外交叉验证诊断时，还须留 embargo，避免信息窗口相邻污染。
- `TimeSeriesSplit(gap=...)` 只提供按行间隔的基础结构，不自动理解多股票同日分组、发布时间、停牌日或标签区间。
- 训练末尾尚未成熟的标签是缺失，不是“不上涨”。所有 horizon 的成熟状态独立维护。

在下次滚动更新中，已经成熟的旧测试标签可以成为训练数据，但不得改写当时冻结的测试预测，也不得事后替换其训练版本。

### 7.3 评估指标

| 检查对象 | 主要指标 | 解释 |
|---|---|---|
| 概率整体质量 | Brier=`mean((p-y)^2)`；log loss | 严格适当评分，越低越好。Brier 同时受校准与区分能力影响，不单独证明校准好 |
| 相对基准增益 | `Brier skill=1-BS_model/BS_base`；配对日期块置信区间 | base 用训练/历史可得的上涨基准率，不用测试期真实平均上涨率 |
| 校准 | 等频概率分箱的预测均值/实际频率及区间，校准截距/斜率 | 用表格展示；ECE 可作补充，但受分箱方式影响 |
| 方向区分 | ROC-AUC、balanced accuracy、普通准确率和混淆统计 | AUC 高不保证概率校准，准确率也不等于投资收益 |
| 相对排序 | 按日 Rank IC、分位组超额收益、组内风险 | 不能把全市场上行误判为个股选股有效 |
| 收益分布 | Pinball loss、区间覆盖率、区间宽度 | 宽到无参考价值的区间也可能覆盖率很好，两者一起看 |
| 风险模型 | 实际超阈值比例、异常聚集、压力期漏报 | 尾部异常不是独立事件时检验要考虑聚集性 |
| 稳定性 | 各滚动折/年份/波动状态、最差折、参数扰动、随机种子扰动 | 不能只报全期平均，不能只挑盈利年份 |
| 研究经济性 | 按预测分组的收益、回撤、周转与预登记成本敏感性 | 是模型可用性诊断，不输出执行/仓位指令 |

基准至少包括历史可得上涨率、只用市场/风险状态的小模型、去重复的组间等权和简单价格模型。不能仅与“抛硬币 50%”比较，因为市场本身有非零漂移。

如果研究一个明确的分组组合收益，才计算其年化收益、Sharpe、回撤等，并记录再平衡、重叠持有、融资/卖空假设。不能把每天一个重叠 60 日收益视为可复利交易序列。没有合法投资组合收益定义时，不报告“模型年化收益”。

用整块日期重采样，保留同日股票共振。对时间块长度至少覆盖最长标签，并对更长依赖做敏感性分析。不能把一万个股票日当一万个独立样本；报告股票数、独立日期、覆盖市场阶段和近似有效样本量，后者注明估计方法。

若比较大量组合策略，可增加回测过拟合概率 PBO、Deflated Sharpe Ratio 等诊断，记录全部试验次数、试验相关性和收益非正态性。它们不替代最终未触碰的时间留出，也不为未来收益作保证。

### 7.4 发布规则：分维度，不设“一票否决所有研究”

研究结果分别报告以下维度，不将其压缩成来源不明的单一“置信度”：

| 维度 | 关注 |
|---|---|
| 数据可靠性 | 历史完整性、行动、单位、可知时点、缺失与来源差异 |
| 样本外优势 | 对朴素/风险基准是否有重复出现的增益 |
| 概率校准 | 预测频率是否接近实际频率 |
| 跨期稳定性 | 增益是否只集中在少数市场阶段 |
| 风险刻画 | 收益区间和尾部是否过度乐观 |
| 可复现与运行性 | 同数据同版本能否重算，时延与缓存是否受控 |

描述指标和预测概率分开发布。硬条件只用于具体能力，例如未来字段泄漏导致该次概率实验无效，但不抹去核对正确的当前财务数值。

概率有模型估计值，不代表已经有可用优势。要标为“已验证的概率参考”，应在预登记的样本外区间优于基准，并有块置信区间和校准证据支持；增益区间跨零时标为“未证实优于基准”。可展示基准率和描述性数据，不必伪装成更精确的预测。

“没有发现稳定预测优势”是允许且有参考价值的结果。价格模型失效也不能偷偷改用新闻主观判断填一个概率。

## 8. 防过拟合、泄漏、重复计算与无效指标

| 风险 | 控制方式 | 必须有的验收测试 |
|---|---|---|
| 修订财务/宏观泄漏 | 版本化 as-of 查询 | 加入未来修订后，旧 cutoff 的特征仍不改变 |
| 盘后公告泄漏 | 统一时区与实际发布时间 | 收盘后发布只影响之后可用的交易时段 |
| 后复权/公司行动泄漏 | 原始价＋独立行动账本，历史截止版本 | 加入未来拆股不能改变已经封存的过去预测 |
| 开盘标签算错 | 用明确参考持有区间处理权益 | 在开盘日除权的新参考持仓不领取前日权益 |
| 训练外拟合 | 变换、缺失填充、聚类、选参均包在训练流程内 | 修改测试值不能改变训练段归一化参数或选参 |
| 标签重叠污染 | 按日期与实际标签区间 purge | 所有折的训练标签结束时间满足边界规则 |
| 幸存者偏差 | 历史证券主表、退市样本与终值规则 | 当前上市名单不能悄悄作为过去全市场池 |
| 单一大盘股示范泛化 | 股票范围与时期写入实验标识 | 仅测 AAPL 的结果不能宣称对所有美股有效 |
| 多重试验/指标挖掘 | 有限候选集、预登记、完整失败记录、留出封存 | 报告尝试总量，不只保存获胜配置 |
| 重复经济信号 | 因子族、相关聚类、组级消融 | 不同时给多个同义指标独立默认权重 |
| 当前上下文混入过去 | 仅实时数据的字段单列 | 当前期权、新闻和评级不得出现在历史特征中 |
| 缺口/停牌误补 | 交易日历、缺失原因、有效区间 | 不把停牌/丢失交易日变成零收益训练样本 |
| 极端日被“清洗”掉 | 数据错误与真实市场尾部区别处理 | 危机日和真实大跌不会因超阈值被自动删除 |
| 虚假成功或旧缓存 | 子接口值校验、原始哈希、获取时间 | HTML、目录、空数组、过期缓存不通过数值准入 |
| 输出精度虚高 | 有效样本、区间和状态标签 | 无法验证的能力输出缺失原因，不默认 0 分或 50% |

相关性不是因果关系。新闻反应与价格同时出现时，不能用同期相关直接解释为新闻导致上涨。

## 9. 计算效率与更新策略

效率目标是增量、去重、批量和可重复，不是减少必须的验证。当前无真实运行基准，因此不承诺“几秒出报告”。

### 9.1 分层存储

- **原始层**：每次获取完整不可变载荷及 hash、抓取时间、来源/权限元数据；凭证不落盘。
- **规范层**：按证券/市场/日期保存原始 OHLCV、行动、财务版本、宏观版本、新闻事件 ID。研究初期采用 Parquet 与 DuckDB 足够，不先引入分布式系统。
- **特征层**：按 feature version、数据版本与 cutoff 保存计算结果和输入依赖。
- **实验层**：固定拆分、尝试台账、模型/校准器、所有样本外预测与指标。
- **报告层**：只读取冻结结果、近期特征和当前上下文；不在每次问询时重训全部模型。

建议 manifest 主键包含市场、永久证券 ID、区间、价格口径、时点政策和原始哈希。旧探测文件没有 manifest 不自动导入。

### 9.2 增量与共享

| 工作 | 优化 |
|---|---|
| 行情更新 | 只补新日期和明确的修订范围，保留 revision 日志 |
| EMA/滚动窗口 | EMA 单步递推；均值/方差用稳定滚动算法；最大值用单调队列 |
| 多窗口特征 | 共享总收益、金额、基准回归等基础序列，避免 RSI/MACD 各拉一次同源行情 |
| 财务指标 | 只在新申报/修订公开时重算，日线 as-of join；不每天重新解析全体 XBRL |
| 宏观数据 | 每序列每 vintage 采集一次，全股票共享，不按股票重复请求 |
| 多期限标签 | 使用同一行动引擎和缓存的持有路径，按标签成熟事件增量生成 |
| 新闻处理 | URL/正文 hash/事件聚类三级去重，改版后的分类结果另存版本 |
| 回测 | 预建时间分区、共享不可变特征矩阵；不能共享跨训练边界拟合的 scaler |
| 并发 | 跨独立来源有限并发、每域限流、指数退避；本地矩阵批量运算 |
| 报告查询 | 一次读取缓存的模型/特征版本，多市场并行，避免重复训练 |

特征缓存键必须包含原始数据版本、行动版本、财务映射版本、发布时间规则、算法和参数。新股息/拆股/修订应沿依赖关系失效受影响区间；只按 ticker+date 缓存会产生难以察觉的旧结果。

为不同阶段记录耗时：下载、解析、验证、join、特征、拟合、推理、报告。先测瓶颈，再决定是否优化。初期模型小，网络等待和历史可知 join 通常比推理更值得优化，但必须用实测证实。

## 10. 最终向用户交付的内容

不只给“看涨/看跌”，也不倾倒几十个重复技术指标。单条消息包含量化结论、新闻结论和综合摘要，数值均可追溯。

### 10.1 量化部分

| 内容 | 要回答的问题 |
|---|---|
| 标的、市场、币种、截止时刻 | 这是哪份数据，是否已过期？ |
| 各期限绝对上涨与超额概率 | 按哪种收益区间定义，是否已校准和优于基准？ |
| 条件收益中位数、上下分位 | 胜率之外，可能赚亏多少？ |
| 下行风险与历史压力 | 低概率大亏有没有被掩盖？ |
| 趋势/质量/价值/风险/宏观贡献 | 主要证据是什么，是否只是大盘 beta？ |
| 预测冲突与适用范围 | 短期与长期是否相反，某类行情是否弱？ |
| 验证摘要 | 哪段真正样本外数据，多少独立日期、哪些股票和市场阶段？ |
| 数据与模型限制 | 缺失哪些字段，哪些能力只作描述？ |

展示模板只定义结构，不填假数字：

| 期限 | 绝对上涨概率 | 跑赢基准概率 | 收益中位数及区间 | 下行风险 | 验证状态 |
|---|---|---|---|---|---|
| 1 交易日 | 已验证值或“不发布” | 同左 | 可用值或“样本不足” | 合格结果或缺失原因 | 市场/期限单独判断 |
| 5 交易日 | 同上 | 同上 | 同上 | 同上 | 同上 |
| 20 交易日 | 同上 | 同上 | 同上 | 同上 | 同上 |
| 60 交易日 | 同上 | 同上 | 同上 | 同上 | 同上 |

概率与风险估计不作无意义小数精确展示。贡献是模型内统计分解而非因果解释；高度相关因子按组解释，不给每个同义指标一段相同理由。

### 10.2 新闻与综合部分

新闻按既定七档加“证据不足”展示，列证据来源、事件时间、是否已被价格反应。当前新闻不在模型内时必须写清“作为上下文，不调整上述概率”。

综合摘要可以说明量化与事件是否一致、最主要风险及结论适用窗口。它不能通过一句主观乐观评价覆盖量化失效，也不输出买卖指令、仓位或图表。

缺少概率时仍可交付有用结果：真实趋势和回撤、财务可比性、历史风险暴露、事件证据、数据缺口及“尚无证据优于朴素基准”。信息不足不是无条件中性。

## 11. 可执行建设单元与验收产物

不再以增加来源数量为进度。以下工作都围绕已有或已确认能获取的数据。

| 单元 | 交付物 | 验收标准 |
|---|---|---|
| A. 历史数据与行动 | 全载荷 manifest、证券主表、交易日历、原始价与行动测试集 | 异常/缺口清单；拆股前后财富连续性；行动生效/可知时点；不混入旧复权文件 |
| B. 描述性因子 | 上述价格风险小集合、单位/时点校验、指标解释 | 手算小样本对照；前缀不变性；变换和缺失确定性 |
| C. SEC 与宏观 as-of | 财务季度/TTM 面板、宏观 vintage 表、发布时间映射 | 未来修订加入不改变历史特征；报告累计正确拆解 |
| D. 研究与消融 | 因子卡、训练内相关性簇、滚动样本外预测 | 对每个市场/期限记录全部尝试及基准差异，无随机拆时序 |
| E. 概率/风险发布 | 校准器、分位模型、验证报告、适用范围 | 独立校准、时间块区间、稳定性与覆盖率；不过关不强发概率 |
| F. 上下文集成 | 新闻/日历/期权等带时间和证据的旁注 | 不改写历史预测，不把当前快照伪造为过去历史 |

这些单元是完整建设规格，而不是本次已经完成的模型。本次已完成数据就绪度复核、指标和计算口径设计、模型与验证协议、输出定义，以及 Census 密钥接入验证。尚未训练、未执行完整历史回测、未测得预测优势，也未生成个股上涨概率。

## 12. 方法依据

以下文档/论文在本次通过保持 TLS 校验的下载读取。下载副本位于 `runtime/method-references/`；模型参数和启用门槛不是从论文直接照搬的“保证值”。

1. [scikit-learn：Probability calibration](https://scikit-learn.org/stable/modules/calibration.html)：校准数据与拟合数据分离，sigmoid/isotonic，Brier 同时涉及校准、区分力和不确定性。
2. [scikit-learn：TimeSeriesSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)：时间顺序和 gap 的基础实现，不自动替代金融标签区间净化。
3. [Bailey 等：The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)：大量试验后的虚假发现与 PBO/CSCV 诊断。
4. [Bailey 与 López de Prado：The Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)：多重选择和收益非正态带来的表现膨胀。

来源分析依据为本地实测数据与 [数据就绪度核对](ANALYSIS_DATA_READINESS_2026-11.md)。该设计不依赖购买新源来掩盖当前能力边界，也不把来源可用性当成预测有效性。
