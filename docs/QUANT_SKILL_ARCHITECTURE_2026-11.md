# 统一美港股量化与新闻研究 Skill 整体架构

日期：2026-11-06。

状态：架构设计，尚未实现。本文不代表已经建立完整历史数据库、训练模型、执行样本外验证或取得预测优势。

主要依据：[多因子量化分析与概率评估设计](QUANT_ANALYSIS_DESIGN_2026-11.md)。数据能力边界以[数据就绪度核对](ANALYSIS_DATA_READINESS_2026-11.md)为准，不能用旧的来源探测成功记录替代。

本次交付只新增本文档。以下目录、模块、数据对象和运行任务都是建设规格，不创建实际 Skill 入口、脚本、配置、模型或测试代码。

## 1. 总体定位与架构决策

### 1.1 系统定位

建设一个统一的研究 Skill，以共享、可追溯的数据底座支撑美股和港股分析。量化研究与新闻研究并行进入同一份报告，但不混淆统计预测和文本判断。

系统按证据能力交付不同层次的结果：

| 产物层次 | 交付内容 | 发布边界 |
|---|---|---|
| 当前描述 | 趋势、波动、回撤、估值、财务状态和事件事实 | 不称为经过验证的未来预测 |
| 历史研究 | 因子关系、条件分组、相关性、消融和样本外实验结果 | 不把相关性称为因果关系，不把探索结果泛化到未验证范围 |
| 已验证预测 | 特定市场、期限、目标和样本范围内的校准概率及风险估计 | 必须绑定冻结模型、独立验证证据和发布资格 |

这是一个统一系统，不是“量化不通过后退回新闻打分”的串行系统。一个维度失败，仅限制依赖该维度的能力。

### 1.2 已确定的架构选择

| 决策 | 选择 | 理由 |
|---|---|---|
| 产品入口 | 一个 Skill，按研究任务路由 | 避免美股、港股、新闻和量化各自维护冲突规则 |
| 运行形态 | 本地模块化单体 | 初期采用 Parquet 与 DuckDB，不引入微服务或分布式训练 |
| 计算职责 | 确定性数据与统计引擎计算数值；语言模型组织请求、证据解释和文字表达 | 概率、收益和权重不能由自然语言判断临时编造 |
| 市场隔离 | 共享契约和算法目录，独立维护美港日历、数据准入、模型和校准器 | 相同因子名称不意味着可以共用模型系数 |
| 运行分离 | 数据维护、离线实验、冻结推理和报告生成分离 | 用户查报告时不自动重训或查看封存测试 |
| 价格口径 | 原始价格加独立公司行动台账 | 禁止将厂商复权序列当作训练真值 |
| 数据准入 | 按数据集、字段、用途和覆盖区间判断 | 适配器成功不代表其所有子接口都能用于训练 |
| 发布机制 | 每个市场、期限和目标独立判定 | 不采用“一票否决所有研究”的总门禁 |
| 新闻定位 | 首版作为带证据的上下文；合格历史事件特征以后独立验证 | 七档新闻结论不能直接换算成上涨概率 |
| 交付形式 | 一条消息，包含量化、新闻和综合摘要 | 不输出执行指令、仓位配置或图表 |

保持 US/HK、免费来源和个人研究范围。保留用户已确定的东财、新浪、腾讯及 Tiingo 的适用位置和来源风险标记。不使用任何港股 Yahoo 路径，不以购买新源或反复索取无法提供的港股授权材料作为前置条件。

## 2. 分层框架与依赖方向

### 2.1 逻辑分层

| 层 | 核心模块 | 职责 | 主要输入 | 主要输出 |
|---|---|---|---|---|
| 交互层 | Skill 入口、任务解析、说明文档 | 将用户需求转换为明确请求，选择参考规范，说明能力边界 | 用户需求、静态规范 | 研究请求、最终消息 |
| 控制层 | 编排、策略解析、任务状态 | 固定市场、截止时刻、数据版本和任务范围，调度依赖并收集局部失败 | 请求、策略版本 | 运行计划、运行清单、能力状态 |
| 采集层 | 来源适配、传输、子请求验收 | 在已准入来源范围内更新数据，记录完整获取证据 | 查询计划、来源政策 | 原始载荷、获取回执、局部错误 |
| 证据底座 | 证券身份、交易日历、版本存储、时点查询 | 统一身份、单位、公开时间和版本，提供历史可知视图 | 原始证据、规范规则 | 规范数据、冻结数据快照 |
| 分析层 | 公司行动与收益、因子、当前上下文 | 计算有口径的描述特征、事件证据和风险状态 | 冻结快照、因子目录 | 特征观察、上下文包、收益路径 |
| 研究层 | 数据集、因子检验、模型、校准、评估 | 执行预登记的时间顺序实验，形成候选模型和验证证据 | 特征、成熟标签、实验协议 | 因子卡、模型工件、样本外预测、评估报告 |
| 发布层 | 模型注册、能力判定、冻结推理 | 选择适用的已验证模型，执行推理和目标级发布检查 | 当前特征、注册工件、验证证据 | 量化结果包、发布决策 |
| 表达层 | 报告组装、证据引用、综合摘要 | 按固定结构表达结果，保留冲突与缺失原因 | 量化结果包、上下文包、运行清单 | 可追溯报告、单条用户消息 |

### 2.2 必须保持的边界

- **采集不决定预测资格。** 它只能证明本次取得了什么，不能证明历史时点正确或存在预测优势。
- **计算不自行请求新数据。** 因子、标签和模型只读编排层选定的快照，不能绕过来源政策或版本锁定。
- **报告不拟合模型。** 报告模块不能改变标准化参数、模型系数、校准器或发布阈值。
- **上下文不改概率。** 未进入该模型版本的新闻、期权和评级只能影响文字解释，不能加减已计算概率。
- **研究不修改封存预测。** 后续训练可以使用已经成熟的旧标签，但不能重写当时的预测和工件绑定。
- **市场不隐式互换。** 缺少港股数据时，不能临时使用美股模型、Yahoo 港股数据或不同收益口径的基准。

各模块通过版本化契约交换结果，不读取其他模块的私有临时文件。来源变更影响采集和准入，不应要求修改每个因子的算法。

### 3.2 Skill 入口文档的职责

入口文档保持精简，只说明：

1. 什么请求属于本 Skill，什么请求不属于本 Skill。
2. 如何确定市场、证券身份、截止时刻和研究任务。
3. 按任务加载哪些参考文件，避免每次把整个来源表和算法目录装入上下文。
4. 哪些结果由计算引擎提供，哪些属于文本上下文。
5. 如何保留局部失败、不发布原因和验证状态。
6. 如何组织单条最终消息。

入口不内嵌完整因子公式，不保存密钥，不允许语言模型自行设定最终权重、概率或来源豁免。

策略目录分别管理来源用途、时点口径、因子注册、实验协议和发布规则。它不保存学习得到的权重或校准参数，这些参数属于绑定实验与数据版本的模型工件。

### 3.3 任务类型

| 任务 | 作用 | 可以产生 | 明确不做 |
|---|---|---|---|
| 当前研究报告 | 查询截止时刻可用数据，读取适用冻结模型，整合当前新闻 | 描述、合格预测、上下文和限制 | 不隐式重训，不临时选参 |
| 数据维护 | 补充已有来源的新记录、修订和发布证据 | 新数据版本、质量清单、受影响依赖 | 不自动晋升模型，不把旧探测文件当训练集 |
| 历史研究 | 按登记协议检验因子、相关性、基线和模型 | 因子卡、实验台账、候选工件 | 不用最终测试选配置，不宣称已验证预测 |
| 验证与发布审查 | 读取冻结实验和成熟标签，检查校准、稳定性与范围 | 目标级发布资格、拒绝原因 | 不修改被评估的历史预测 |
| 结果复现 | 按既有报告清单重算或重组结果 | 同版本复现结果、差异审计 | 不以最新数据冒充原报告数据 |

默认进入当前研究报告。没有适用模型时，照常交付合格描述和新闻证据，不将默认任务升级成耗时未知的训练任务。

## 4. 数据准入与能力模型

### 4.1 数据就绪度是多项证据，不是来源总分

每个具体数据集及其必要字段分别记录以下状态：

| 状态字段 | 判断内容 | 不能替代的证据 |
|---|---|---|
| `observed_value` | 是否解析到语义正确的数据值 | HTTP 成功、HTML、目录或文件头不等于有效数据 |
| `full_payload_saved` | 是否在允许范围内保存完整载荷和哈希 | 截断样本或覆盖写入的 smoke 结果不能证明完整历史 |
| `history_validated` | 所需区间、交易日连续性、修订和证券范围是否核对 | 行数多不等于连续，也不等于无幸存者偏差 |
| `availability_validated` | 历史公开时点和版本选择是否有证据 | 统计期间、结算日和今天的获取时间不能冒充公开时间 |
| `usage_allowed` | 当前用途、存储、训练和交付是否处于允许范围 | 技术可访问不自动证明用途许可 |
| `eligible_for_training` | 对特定实验，必要数据、语义、时点与用途条件是否同时满足 | 必须由准入政策推导，不能由适配器手工声明成功 |

这些状态可以按覆盖区间变化。某个年度通过，不代表同一字段所有年度通过。用途许可也需要区分已允许、未允许和待核实，不把未知当作允许。

描述、历史训练和衍生结果交付分别检查其用途范围。保留已选个人研究来源及风险标记，不把这种选择扩展成任意再分发或任何用途的许可。

### 4.2 能力的最小判定单位

能力标识至少包括：

- 市场及已验证证券范围。
- 输出类型，例如原始报价描述、行动一致的趋势、当前财务、历史因子研究、绝对概率、超额概率、收益分位和路径风险。
- 预测期限及目标口径。
- 所需数据、算法和验证版本。
- 有效日期范围及当前截止时刻。

例如，缺少同口径基准只关闭超额概率，不能同时关闭绝对概率、当前财务和新闻。方向概率未证实优势，也不能自动抹去独立通过的历史风险描述或收益分位验证。

### 4.3 不混用的状态轴

| 状态轴 | 示例状态 | 用途 |
|---|---|---|
| 实现状态 | 仅设计、已实现、已停用 | 防止把架构规格写成运行能力 |
| 数据使用层级 | 不可用、仅上下文、可描述、可用于历史研究 | 确定数据能进入哪一层 |
| 验证状态 | 未执行、未证实优势、通过、实验无效、漂移后暂停 | 记录统计证据，不由数据就绪度直接推出 |
| 发布状态 | 发布描述、发布标明口径的基准、发布已验证结果、不发布 | 决定最终消息可出现什么 |

“证据不足”是新闻结论状态。“未证实优于基准”是模型证据状态。二者都不等于“中性”，也不等于默认概率。

### 4.4 当前数据边界如何落到架构

| 数据范围 | 首版位置 | 扩展条件或限制 |
|---|---|---|
| 美股原始日线及部分行动记录 | 优先建设价格、行动和风险底座 | 核实完整载荷、单位、缺口和行动覆盖，不把零散拆股探测当完整台账 |
| SEC 财务事实及申报索引 | 当前事实与历史财务底座候选 | 补齐公开时点、修订、季度拆分和标签映射后才能按时点入研究 |
| 美股宏观与版本来源 | 共享市场状态候选 | 按序列核实 vintage 和发布批次，不能使用今天修订值回填 |
| 港股原始日线及当前 F10 | 保留港股描述和上下文支线 | F10 不进入无公告时点的历史模型；未知行动覆盖的收益标签不发布 |
| 新闻元数据、官方摘要、当前日历 | 当前事件发现、风险提示和前向积累 | 不冒充全文证据、完整历史新闻或公告前冻结的一致预期 |
| 当前期权、部分持仓与成交统计 | 独立背景 | 没有历史链或正文记录时不暗中参与预测 |
| 港股通方向未确认、未解析统计表、仅文件头数据 | 隔离或待核实 | 不生成方向因子或预测值 |
| Census 人口样本 | 已核实统计背景 | 不自动扩展为月度经济数据覆盖或短期股价因子 |

适配器、子请求、数据集和字段都保留独立回执。一个子接口失败，不能被同一适配器另一个成功接口覆盖。

## 5. 核心数据契约

契约是模块间的稳定接口规格，不是本次编写的类或数据库表。标识、时间、单位、版本、缺失和来源字段需要显式存在，不能藏在自由文本中。

### 5.1 请求、身份与原始证据

| 契约 | 必要内容 | 关键约束 |
|---|---|---|
| `ResearchRequest` | 任务、证券、市场、截止时刻、期限、目标、新闻观察窗、更新策略 | 默认期限为 1、5、20、60 个当地交易日；新闻观察窗独立于预测期限 |
| `SecurityIdentity` | 永久证券 ID、有效期内代码、交易所、证券类型、币种、上市与退市记录 | 使用证券 ID 连接历史，不使用当前 ticker 当永久身份 |
| `SessionCalendar` | 市场、时区、交易时段、节假日、提前收盘和版本 | 标签依据真实市场交易时段，不依据数据文件的下一行 |
| `AcquisitionReceipt` | 来源、数据集、子请求、脱敏参数、请求与接收时间、返回类型、覆盖与分页状态 | 区分合法空结果、未穷尽、限额和失败；覆盖声明必须有查询证据 |
| `RawManifest` | 完整载荷位置及哈希、回执、解析版本、用途与保留政策 | 不纳入缺少清单的旧探测载荷，不把凭证写入元数据 |
| `EvidenceEnvelope` | 经济时间、公开时间、首次可得时间、系统接收时间、时间精度、版本及定位 | 日期精度和估计时间必须标记，不能假装精确时刻 |

### 5.2 规范数据与计算输入

| 契约 | 必要内容 | 关键约束 |
|---|---|---|
| `PriceBar` | 原始 OHLCV、成交量单位、币种、交易时段、来源版本及质量状态 | 数据缺口与停牌分开，不把缺失价格填成零收益 |
| `CorporateActionEvent` | 行动类型、经济生效日、公开与可得时点、权益单位、换股或现金参数、确认状态 | 拆股、股息和复杂行动分开处理，无法支持的事件明确阻断相关收益 |
| `ActionCoverage` | 证券、覆盖区间、检查证据、未解决事件和版本 | 没有行动记录，不等于已经证明区间内没有行动 |
| `FinancialVintage` | 财报期间、累计或单季、币种、概念映射、accession、修订关系和可知时点 | 财务版本必须支持同口径季度与 TTM 重建 |
| `MacroVintage` | 序列、统计期、数值、单位、发布批次、修订及历史可得证据 | 不把同一宏观发布复制为许多独立日观测 |
| `BenchmarkSpec` | 市场、币种、价格或含息口径、参考时段、历史覆盖 | 不能将个股总收益减价格指数收益标为纯选股超额 |
| `DataSnapshot` | 选定原始清单、规范版本、时点政策、截止时刻和证券范围 | 一次运行读同一快照，不能混用新旧行动或财务版本 |

### 5.3 特征、实验与输出

| 契约 | 必要内容 | 关键约束 |
|---|---|---|
| `FactorSpec` | 经济假说、因子族、算法、窗口、输入口径、方向政策、最低覆盖和缺失规则 | 显示指标不自动成为模型特征；候选与启用分开 |
| `FeatureObservation` | 因子版本、证券、截止时刻、原值、变换引用、输入依赖和缺失原因 | 当前描述值与训练内标准化值分开保存 |
| `LabelRecord` | 目标、期限、参考开始与结束、行动路径、基准、成熟及修订状态 | 下一开盘开始的标签不能用前日收盘指数比值替代 |
| `DatasetManifest` | 样本范围、股票池依据、快照、因子与标签版本、分区和排除原因 | 明确哪些日期已用于研发，哪些仍未触碰 |
| `ExperimentProtocol` | 候选预算、基线、嵌套分块、选参、校准、评估及发布标准 | 必须在查看对应结果之前登记 |
| `ModelArtifact` | 市场、期限、目标、适用范围、输入 schema、变换、模型、校准引用、代码及依赖版本和随机种子 | 推理只能使用匹配工件，不能临时删特征再沿用原系数 |
| `CalibratorArtifact` | 绑定的冻结模型、独立校准区间、输入预测版本、方法、参数及有效范围 | 不与其他模型或期限互换，不使用模型选参或最终测试标签 |
| `ValidationEvidence` | 样本外预测、基准差异、校准、区间、稳定性和有效样本证据 | 保存所有尝试与失败，不只保存获胜配置 |
| `ContextEvent` | 事件 ID、来源证据、实体、事件时间、首次可知、分类和版本 | 事实、推论、标题证据和全文证据分开 |
| `CapabilityDecision` | 判定范围、依赖、验证与发布状态、原因和恢复条件 | 决策按具体目标做，不压缩成单一置信度 |
| `RunManifest` | 请求、政策、代码与依赖版本、数据及工件引用、阶段耗时、错误和输出哈希 | 复现使用原运行绑定，不能悄悄升级算法、数据或模型 |
| `ResearchResult` | 分期限量化结果、上下文、限制、冲突、运行与引用清单 | 缺失值附原因，不用零分或 50% 占位 |

契约之间使用清单和版本 ID 连接。最终报告中的每个数值能追溯到输入快照、计算口径及对应工件。

## 6. 时间、公司行动与收益底座

### 6.1 两种历史查询必须区分

| 查询方式 | 时间准入 | 可以证明什么 |
|---|---|---|
| 历史可知重建 | 有独立历史发布证据，首次可得时点及登记的处理延迟均早于截止 | 该值在当时理论上可获得，不证明本系统当时实际取得 |
| 原运行回放或实时研究 | 还要求系统接收和处理完成时点早于截止 | 该次系统运行确实能够使用该值 |

缺少历史发布证据的数据，只能从系统前向记录开始积累。保守地延后一个交易日不能消除最新修订值回填问题。

时间存储统一保留 UTC 时刻和当地交易时段标识。美国夏令时、提前收盘及香港假日由版本化日历管理，不写死一个通用收盘时间。

跨市场上下文也按实际可得时间连接。港股截止时尚未发生的同日美股收盘，不能因日期相同进入港股特征。

### 6.2 行动与收益的职责划分

公司行动模块提供统一的权益转换与收益路径计算，供描述因子、标签和风险共用。它不是交易执行或账户管理系统。

- **历史特征路径**仅使用截止时已经可知且已生效的行动，将历史价格和成交量转换到可比较单位。
- **经济收益路径**使用明确的拆股与现金权益口径，现金股息再投资假设沿用主设计。
- **估值计算**使用当时原始价和当时已知股数，不使用总收益指数代替股价。
- **预测评估路径**从下一当地交易日开盘到第 h 个交易日收盘，按参考进入时点确定权益归属。

绝对上涨标签以该区间毛总收益严格大于零定义。超额标签以个股毛总收益严格超过同口径基准定义，零收益或零超额不归入上涨类。

开盘日已经除权的现金权益不归当日新进入的参考持有。供应商现金权益按新股或旧股计价必须先核实，不能直接套用字段。

供股、分拆、特殊股息和并购换股需要专门规则。未实现或证据不足时，相关收益窗口明确缺失，不套用普通拆股加现金的公式。

### 6.3 缺口、退市与晚确认事件

- **缺少预定开盘价**时，该参考标签缺失，不顺延到一个方便的交易日。
- **停牌或丢失交易日**不能填零，标签和逐日路径分别判断其完整性。
- **退市终值未确认**时，不凭空补零，也不悄悄删除证券来改善样本表现。
- **晚确认行动或结算**形成新的标签及评估版本，不重写历史封存预测。
- **新增未来行动**不能改变过去截止时的特征。后续发现过去数据错误时，另建修订实验并记录原实验受影响范围。

港股缺少已核实行动覆盖时，允许单列原始报价变化。它必须明确不等于经济总收益，不能据此强发投资收益概率。

## 7. 量化分析与模型框架

### 7.1 因子按经济含义组织

| 因子组 | 首版候选方向 | 模型使用方式 |
|---|---|---|
| 趋势与反转 | 中期动量、跳月长期动量、平滑趋势、短期残差反转 | 按期限研究方向，不强制短期与长期同号 |
| 波动与流动性 | 实现波动、波动变化、回撤、异常成交量、Amihud、beta、特异波动 | 风险状态不天然等于看涨或看跌票 |
| 价值 | 盈利收益率、自由现金流收益率 | 使用当时市值，按行业适用性处理 |
| 质量与增长 | ROA、应计项、营收增长、净负债 | 使用历史可知且口径兼容的财务版本 |
| 市场与宏观 | 曲线、融资变化、通胀、活动、汇率及已合格市场风险 | 按真实发布更新；共同时点不当作独立股票观测 |
| 合格事件 | 财报变化、已披露内部人交易、已核实新闻事件等 | 仅在历史时点、正文、语义和用途准入后启用 |

RSI、MACD、布林位置和 ATR 可以作为解释性指标，不默认与同义趋势或波动特征一起重复计票。算法细节引用主设计，不在不同模块各维护一份公式。

### 7.2 特征计算与训练变换分离

特征模块输出原始、有时间口径的观察值。标准化、异常值阈值、缺失填充、相关聚类及残差化属于训练流水线，必须在该折训练块内拟合。

当前描述不依赖一个尚不存在的训练标准化器。显示训练分布下的百分位时，必须明确引用哪一个已冻结参考分布。

缺失数据遵循登记规则：允许的训练内填充附缺失指示与数据年龄；严重缺失使用另行验证的简化模型，或暂停对应预测。不能在推理时删掉一组因子再临时归一化原模型权重。

### 7.3 相关性和权重的治理

因子目录登记变换族和经济组，研究层在训练段检查 Pearson、Spearman、共同缺失及共同来源。高相关告警线的初始候选沿用主设计，但阈值不是自动证明冗余的定律。

研究比较的顺序为：

1. 历史可得基准率及简单市场风险基线。
2. 训练内去重复的组内、组间等权研究基线。
3. 各市场、期限独立的正则化模型。
4. 只有内层样本外证据支持时，才加入有限复杂模型或已验证模型的收缩组合。

不设置“技术四成、基本面三成”一类永久主观权重，不采用绝对 IC 直接配权。风险指标不为制造统一看涨分数而硬改方向。

系数、组合权重及校准器分别记录版本，按预登记更新周期重新验证。报告中的模型贡献按组解释，并明确是统计分解，不是因果归因。

### 7.4 模型与目标组织

| 目标 | 首选模型或研究方法 | 独立资格要求 |
|---|---|---|
| 绝对上涨概率 | L2 正则化逻辑回归及独立 sigmoid 校准 | 市场、期限、收益口径及适用范围匹配 |
| 跑赢基准概率 | 同类模型，使用同口径超额标签 | 额外要求合格基准 |
| 条件收益中位数及分位 | 正则化线性或分位数回归 | 样本外分位损失、覆盖和宽度检查 |
| 下跌超过阈值 | 独立目标模型或已验证条件分布 | 阈值预登记，样本足够，不能由上涨概率直接推算 |
| 路径风险 | 基于逐日参考持有路径的独立标签和模型 | 区分收盘路径与包含盘中极值的路径 |
| 极端尾部 | 有足够证据的条件尾部分布；不足时保留历史压力描述 | 少量长周期独立窗口不发布精确期望尾部损失 |

首版条件收益分位固定为 10%、50% 和 90%。方向模型默认从 L2 正则化开始，Elastic Net、非参数校准或复杂模型只有内层验证支持才启用，不作为实时回退。

多股训练按登记目标控制日期总权重，评估同时给出等日与等样本结果。不能为了类别平衡随意重采样涨跌；改变类别权重时必须恢复目标分布并重新校准。

每个市场和 h 拥有自己的模型、标签与验证。多个目标可共享原始特征，但发布资格不能相互代替。多市场联合建模只是后续研究候选，不是首版缺数据时的默认回退。

多期限上涨概率不由单日概率连乘、不由独立每日事件公式推导，也不以正态假设与平方根时间缩放当作最终真值。

分位数交叉及同期限输出的语义冲突，需要采用冻结且验证过的修正政策。不能为使报告看起来一致而手改数字。不同期限方向不一致是允许结果，不强加概率随期限增加的单调性。

## 8. 新闻、事件和其他上下文

### 8.1 事件处理链

当前上下文按以下顺序处理：发现记录、核对许可与证据范围、规范实体与时间、去重聚类、提取事实、分类并生成引用。

去重分为 URL、正文哈希和事件聚类。转载与更新保留为证据关联，不被计为多个独立利好。更正和后续进展保留独立版本，不覆盖旧事件状态。

证据对象区分标题、摘要、许可全文、官方摘录和原始数值。只有标题时，不能写成已核对公告正文。SEC 索引、Form 4 目录或日历行不等于内部人交易正文、13F 持仓或冻结的一致预期。

### 8.2 七档新闻结论

方向等级保持：极大利好、高度利好、中度利好、中性、中度利空、高度利空、极大利空。另设独立“证据不足”。

每项结论至少说明：

- 已证实事实与相关证券。
- 经济传导方向、重要性依据和适用时间窗口。
- 证据来源、可知时间、证据定位及缺口。
- 相互矛盾的证据或仍待确认条件。
- 事件之后已经观察到的价格变化及其区间。

观察到事件后涨跌，不证明由该事件导致，也不证明市场已经充分定价。新闻等级不等间距，不映射成预设收益、数值权重或上涨概率。

不要求用户建立人工逐条标注的训练样本。先采用固定分类规范、证据约束和版本记录开展当前新闻研究；一致性抽查与历史模型训练准入分开。

历史文本即便有正确发布时点，也不能自动证明今天的分类方法在当时可部署。分类方法和模型版本变化必须记录。无法排除事后知识影响时，回溯结果标为探索，预测资格依靠合格协议和后续前向验证建立。

### 8.3 上下文与预测的连接方式

首版报告明确写明：当前新闻作为上下文，不调整上述模型概率。

若以后启用事件因子，需要创建新因子版本和新模型版本，重新执行时点准入、消融、校准和验证。不能把实时新闻分数插进既有价格模型。

当前期权隐含分布属于风险中性背景，不替代真实世界方向概率。资金流、持仓、评级和日历也必须保留其数据覆盖及陈旧度限制。

港股公司公告无法取得合格证据时，保留公司事件缺口，并继续交付合法可用的市场新闻与其他已核实上下文。不新增 HKEX 自动采集路径，也不反复要求用户提供已明确无法提供的材料。

## 9. 运行流程与任务生命周期

### 9.1 当前研究报告流程

1. **解析请求。** 确定任务、市场、永久证券身份、截止时刻和期限；身份冲突不能靠默认猜测掩盖。
2. **锁定政策。** 读取来源用途、时间、收益、因子及发布规则版本。
3. **检查数据。** 按请求的更新策略使用合格缓存或增量更新，分别记录新鲜度与局部失败。
4. **冻结快照。** 选择截止时可用数据和一致的规范版本，形成不可变运行清单。
5. **并行开展独立分析。** 计算描述特征、处理当前上下文、查找适用的已发布模型。
6. **执行冻结推理。** 核对特征、市场、期限、目标、模型范围和校准器绑定。
7. **逐能力审查。** 分别判定概率、分位、路径风险、描述和新闻可以交付到什么程度。
8. **组装报告。** 显示冲突、限制和缺失原因，引用已冻结结果，不重新计算权重。
9. **保存复现清单。** 保存报告、输入及工件引用、阶段状态和来源证据。

数据更新失败时，可以使用政策允许且明确披露日期的旧数据。不能把旧缓存写成最新行情，也不能混入截止后才到达的记录。

### 9.2 数据维护流程

来源允许范围检查、子请求采集、载荷验收、不可变保存、规范化、质量审计、版本提交、依赖失效依次完成。

修订先形成新版本，再使受影响的特征和标签缓存失效。原始载荷与旧清单保留，已封存报告仍指向旧版本。获取不完整时只提交实际覆盖和错误，不扩大成功区间。

### 9.3 历史研究与发布流程

先固定实验协议、数据快照和股票池，再构建特征与成熟标签。按时间推进训练、开发验证、校准和测试，保存每次尝试及每个样本外预测。

候选模型经验证后进入注册记录。只有目标级发布检查通过，才可成为默认报告使用的活动工件。一次报告运行只读取注册快照，不在运行中切换模型版本。

模型状态包括候选、验证通过、活动、观察、暂停和退役。数据错误、分布超出适用范围或校准恶化触发具体能力的暂停。恢复依赖新的验证证据，不依赖主观调权。

### 9.4 任务的运行状态

任务状态区分计划、执行、完成、部分完成和失败。模块输出包含错误类型、影响能力和已经完成的结果。

采集阶段允许有限重试与每域退避。确定性输入错误、用途禁止或单位不明不能靠换来源、无限重试或填默认值“恢复”。重新运行同一版本任务不能生成重复实验记录或悄悄覆盖工件。

## 10. 验证与目标级发布规则

### 10.1 验证层的结构

| 验证环节 | 必须冻结的内容 | 必须保存的证据 |
|---|---|---|
| 实验登记 | 经济假说、候选预算、分块规则、基线和验收政策 | 登记时间、版本、研发已见区间 |
| 训练块 | 清洗、填充、变换、相关聚类和拟合 | 训练输入和全部拟合参数 |
| 开发验证块 | 有限候选和超参数的取舍 | 每次尝试及失败 |
| 后续校准块 | 已选模型的独立校准 | 校准输入、方法和工件 |
| 后续测试块 | 全流程冻结后形成预测 | 预测时版本及以后成熟的真实标签 |
| 最末封存区间 | 研发期间不查看 | 每次访问、最终审查和使用记录 |

所有同日证券进入同一时间分区。边界按实际标签区间 purge，必要的后段交叉验证诊断增加 embargo。随机拆行和仅按文件行数留 gap 均不能满足该协议。

每个期限独立维护标签成熟状态。校准、重训和监测只能使用已经成熟的标签。对旧测试标签的新利用不改变原来的样本外预测记录。

### 10.2 评估证据

- **概率质量**包括 Brier、log loss、对历史可得基准的配对差异及日期块区间。
- **概率校准**包括分箱频率、区间、截距和斜率，不能仅用准确率代替。
- **因子价值**包括按日 Rank IC、条件分组、稳定性和组级消融。
- **收益分布**同时检查分位损失、覆盖和宽度，不以无限宽区间换取漂亮覆盖率。
- **风险可靠性**检查超阈值频率、聚集和压力期漏报，保留真实极端收益。
- **适用范围**记录证券数、独立日期、市场阶段和注明估计方法的有效样本证据。

块重采样保留同日股票共同波动，块长度考虑最长标签和更长自相关。长周期的大量重叠股票日，不等于同样数量的独立季度样本。

探索阶段按因子族和期限控制多重检验，并记录试验总量与依赖性。显著性表不能替代未触碰的时间留出。概率估计误差需按日期块重采样并重新拟合登记的完整训练与校准流程，不能与未来收益区间混用。

研究经济性只是可用性诊断。没有明确合法的组合收益定义，不报告模型年化收益或将重叠持有收益当可复利序列。

### 10.3 发布决策

| 证据状态 | 对用户的交付方式 |
|---|---|
| 数据语义或历史时点不合格 | 不发布受影响预测；可保留另行核对正确的当前描述 |
| 数据可研究但验证未执行 | 发布描述或明确标识的研究结论，不填个股概率 |
| 模型估计存在，但优势区间跨零 | 标为未证实优于基准；默认报告保留合格基准和描述，不伪装成更可靠预测 |
| 独立校准或稳定性不合格 | 暂停相应预测资格，保留其他通过能力 |
| 数据、样本外优势、校准与适用范围均满足登记政策 | 发布绑定验证版本的概率参考 |
| 方向预测不合格，但独立风险能力合格 | 发布合格风险结果，不以方向失败总否决 |

候选模型数值可以保留在离线实验审查中，但不作为默认个股研究报告的“已验证概率”。基准率也必须说明其训练或历史可得范围，不能默认填 50%。

数据可靠性、样本外优势、校准、稳定性、风险刻画和可复现性分别展示。不生成来源不明的单一“系统置信度”。

### 10.4 需要预登记而非随意补值的参数

模型训练前需要版本化登记：市场截止时刻与供应商延迟、训练和验证窗、覆盖下限、缺失及陈旧度规则、候选与超参数预算、基准定义、概率与风险验收容差、块重采样规则、重估及漂移检查周期。

主设计中的起始窗口和阈值是有限工程候选，不是已经证明充分的样本量或效果保证。本文不编造通用通过阈值，也不把这些参数留给每次报告生成时临时选择。

## 11. 存储、增量与运行治理

### 11.1 存储分层

| 层 | 内容 | 写入原则 |
|---|---|---|
| 原始层 | 允许保存的完整载荷、哈希、回执和来源政策证据 | 内容不可变，修订另存；凭证不落盘 |
| 规范层 | 证券与日历、原始行情、行动、财务及宏观版本、事件身份 | 按版本追加，可构建历史可知视图 |
| 特征层 | 原值、输入依赖、截止时刻及版本 | 只缓存匹配依赖的结果，不共享跨训练边界拟合参数 |
| 实验层 | 协议、全部尝试、分区、模型、校准与样本外预测 | 预测不可覆盖；标签和评估修订单独留痕 |
| 报告层 | 量化包、上下文、能力决策及引用清单 | 保存结果与依赖绑定，不将其当下一次训练标签 |

初期使用 Parquet 存储面板，DuckDB 提供查询和元数据索引，清单负责冻结版本。并发写入通过受控提交与单写者协调，报告只读已提交快照，不读取半成品数据。

没有许可存储完整正文时，只保存被允许的元数据与定位，并如实标记证据范围。不能为了满足原始层完整性要求扩大许可。

### 11.2 缓存键与失效规则

缓存至少绑定证券永久身份、市场、时间区间、截止政策、数据快照、行动、财务映射、基准、因子算法及参数。训练工件还绑定数据分区和变换版本。

| 变化 | 失效范围 |
|---|---|
| 新行情或行情修订 | 受影响的基础收益、滚动窗口、相关标签及描述 |
| 新行动或行动修订 | 受影响的股数单位、经济收益、估值及标签 |
| 财务新披露或修订 | 自新版本可得时点起的历史可知视图和相关因子 |
| 宏观新 vintage | 自可得时点起的对应市场状态，不重写之前可知值 |
| 事件更正或分类改版 | 对应上下文版本；已入模型时必须另建研究版本 |
| 算法、发布时间政策或基准改变 | 所有依赖该版本的计算和发布绑定 |

旧封存结果不被缓存失效覆盖。修订可改变新计算结果，但必须明确与旧报告不是同一版本。

### 11.3 共享计算与更新

- 行情按新增日期和明确修订范围更新，滚动统计共享基础序列。
- 公司行动引擎共用于总收益、成交量单位和多期限持有路径。
- 财务只在披露或修订可得后重算，日线通过历史可知连接读取。
- 宏观按序列和发布版本采集，全股票共享，不重复按股票请求。
- 标签按各期限成熟事件更新，不每天重建所有历史路径。
- 新闻共享事件去重结果，分类改版另存版本。
- 报告复用冻结模型和特征，跨独立来源采用有限并发和限流。

记录下载、解析、校验、时点连接、特征、训练、推理和报告耗时。没有实测基准前不承诺固定出报告速度，也不以跳过验证换取速度。

### 11.4 安全与用途治理

凭证来自已提供的受控配置，不写入请求清单、日志、载荷路径或报告。来源政策同时控制采集、保存、分析用途和衍生交付。

港股 Yahoo、HKEX 自动获取、未获准的指数用途和禁止用途都不能通过备用适配器绕过。某个指数源不准入时，只有另行验证的替代模型可使用基准实现波动，不能临时换公式。

新闻、公告、下载文件和外部模型工件都作为不可信输入。文本中的指令不能改变研究政策或驱动工具调用。只加载受信、登记且校验哈希的本系统模型工件，隔离不受信下载和解析环境。

个人研究输出不自动授权公开发布。要求外发或再分发时，重新检查对应原始数据和衍生结果的用途边界。

## 12. 最终研究报告契约

### 12.1 一条消息的固定结构

报告首先说明标的、市场、币种、截止时刻及核心结论。随后依次给出量化、新闻和综合摘要，附必要的验证及数据限制，不倾倒全部原始指标。

| 期限 | 绝对上涨概率 | 跑赢基准概率 | 条件收益中位数及区间 | 下行或路径风险 | 验证状态 |
|---|---|---|---|---|---|
| 1 交易日 | 合格值或明确不发布原因 | 独立判断 | 合格值或样本限制 | 合格值或缺失原因 | 独立市场与目标状态 |
| 5 交易日 | 同上 | 同上 | 同上 | 同上 | 同上 |
| 20 交易日 | 同上 | 同上 | 同上 | 同上 | 同上 |
| 60 交易日 | 同上 | 同上 | 同上 | 同上 | 同上 |

没有可靠概率时，表格保留不发布状态，并给出真实可用的趋势、回撤、财务、历史风险和事件证据。不生成演示数字。

### 12.2 表格之外必须交代的内容

- **预测口径。** 下一交易日开盘到约定终点，收益是否含息，基准及币种是否匹配。
- **主要证据。** 按因子组解释趋势、质量、价值、风险和宏观，不把同义指标当多个独立支持。
- **新闻结论。** 使用七档或证据不足，列来源、事件时点、证据范围及模型外上下文说明。
- **冲突和边界。** 允许短期与长期相反，也允许较高上涨概率伴随较厚下跌尾部。
- **验证摘要。** 提供真正样本外范围、独立日期和市场阶段，并区分基准与模型证据。
- **不确定性。** 分开说明未来收益区间、概率估计误差和数据或分布风险。

综合摘要只能说明量化与事件是否一致、适用窗口和主要风险。不能覆盖不发布决定，不能追加主观概率、买卖指令或仓位建议。

### 12.3 典型降级场景

| 场景 | 仍可交付 | 必须限制 |
|---|---|---|
| 港股行动覆盖未确认 | 已确认窗口的描述、明确标记的原始报价变化、当前财务与市场上下文 | 未核实总收益标签及依赖其验证的概率 |
| 无同口径基准 | 合格绝对目标、描述和事件 | 超额概率与纯选股超额解释 |
| 当前新闻只有标题 | 事件发现、来源定位和证据缺口 | 强度超过标题证据的事实判断、全文已核实声称 |
| 基本面无历史公开时点 | 当前财务展示、独立验证的价格模型 | 基本面历史训练与其模型贡献 |
| 长期限有效样本不足 | 历史风险、合格短期限或其他目标 | 长期限精确概率和极端尾部估计 |
| 网络失败且只有旧缓存 | 政策允许的带日期描述、其他来源合格结果 | 最新数据声称、截止后数据混入 |
| 当前方向模型未证实优势 | 基准、描述、合格新闻与独立风险 | 用新闻或中性概率占位的“预测” |

## 13. 建设单元与架构验收

本节定义后续建设边界，不表示这些工作已经完成。

| 单元 | 核心交付 | 依赖及可并行部分 | 必须通过的验收 |
|---|---|---|---|
| A. 契约与历史底座 | 数据契约、来源用途、证券主表、日历、清单、原始价与行动 | 美港各自建设，共享契约；不能只保留美股 | 数值及单位核验、完整性、行动覆盖、身份与退市规则 |
| B. 描述特征 | 有限价格风险集合、因子目录、缺失状态和解释 | 使用 A；港股按确认窗口保留独立产物 | 手算对照、前缀不变性、分母及缺口处理 |
| C. 历史可知财务与宏观 | 季度及 TTM 面板、宏观版本、公开时点映射 | 使用 A；可与 B 并行 | 未来修订不改变旧截止特征、累计季度正确拆分 |
| D. 因子与模型研究 | 因子卡、相关簇、基线、完整实验台账和样本外预测 | 使用已合格的 B、C 子集，不等待全部维度齐全 | 时间分区、真实区间 purge、全尝试记录及范围限制 |
| E. 概率与风险发布 | 独立校准器、分位及风险工件、注册与发布规则 | 使用 D；每个市场、期限和目标分别审查 | 基准增益、校准、块区间、稳定性及风险覆盖 |
| F. 上下文与统一报告 | 事件证据、新闻等级、当前背景、单条消息与复现清单 | A 建立后可并行，不等待 E；始终覆盖可用美港上下文 | 不改概率、引用可追溯、证据不足与局部降级正确 |

建设进度以合格产物、实验和能力为单位，不以新增来源数或适配器成功数为单位。港股缺口是能力状态，不是删除港股分支的理由。

### 13.1 跨模块反例验收

| 反例输入或操作 | 预期结果 |
|---|---|
| 加入未来财务或宏观修订 | 旧截止的特征和封存预测不变 |
| 加入未来拆股 | 过去特征不变化，未来适用窗口另行计算 |
| 盘后公告或迟到行情 | 不能进入更早的截止快照 |
| 修改测试数据 | 训练变换、选参和相关聚类不改变 |
| 训练标签跨入后续校准或测试区间 | 分区校验拒绝该实验 |
| 下一预定开盘缺失或停牌 | 不顺延、不补零，记录标签缺失 |
| 开盘日除权 | 新参考持有不领取前日权益 |
| 只有当前上市名单 | 不宣称无幸存者偏差的全市场历史验证 |
| 高相关技术指标同时出现 | 不自动增加独立默认权重 |
| 真实危机大跌 | 不因超过清洗阈值被自动删除 |
| 某适配器部分子请求失败 | 成功与失败分别保留，能力局部降级 |
| 获取到 HTML、目录或截断载荷 | 不通过对应数值或完整历史准入 |
| 未验证新闻等级输入 | 不改变模型概率 |
| 港股模型缺失 | 不切换到美股模型或港股 Yahoo |
| 某目标验证失败 | 不删除独立合格描述、事件或其他目标 |
| 报告复现时已有新版本数据 | 继续使用原清单，不冒充原版本复现 |

后续还需进行解析契约、缓存失效、并发提交、报告字段和来源用途测试。本次没有编写或运行这些实现测试。
