# 多因子数据与信息渠道缺口 · 2026-11-07

现有渠道足以开始美股多因子描述、因子工程和小范围历史研究。当前主要障碍是覆盖面、历史可知时点和规范化，并非所有信息都需要新供应商。完整的跨股票多因子预测还缺可靠历史股票池、历史股本/行业及更广的财务面板；分析师预期、借券和期权历史等才是需要进一步核实额度或补充授权渠道的项目。

本次只读核验本地原始载荷、Parquet和3个真实运行目录的SQLite登记，不联网抓取，不读取API凭证。旧探测中的“HTTP成功”“若干样本”“完整历史”和“可用于训练”分别记录；许可栏采用当前项目来源政策，不作为新法律判断。

## 缺口优先级与处理路径

P0表示会限制当前基础多因子构建；P1表示后续预测增强或风险层的重要信息；P2表示可延后补充。优先级不代表因子已证明有效。

| 优先级 | 所缺信息 | 现有渠道与状态 | 先做的工作 | 是否需要新渠道 |
|---|---|---|---|---|
| P0 | 广股票池与历史成分、上市/退市、稳定身份 | 东财当前筛选、SEC ticker/申报、新浪若干退市股样本 | 建有效期股票池、代码变更、退市权益；保留当时可投资范围 | 完整无幸存者偏差历史尚无证据，可能需授权历史档案/用户文件；不是多抓当前名单就能解决 |
| P0 | 美股长公司行动历史与可知时点 | Tiingo已有价和行动字段，短窗口完整载荷已保存 | 扩展每股原始载荷、核拆股比例/成交量单位、事件公布及生效时间、覆盖边界 | 初版优先补工程，无需先换供应商 |
| P0 | 七姐妹及更广股票财务PIT面板 | SEC完整NVDA facts/submissions已取得 | 批量补公司；以accession绑定acceptance时间、修订版本、累计拆季度、历史TTM | SEC可继续承担美股初版；主要是工程与覆盖，不是缺来源 |
| P0 | 历史股数、流通股数、市值和行业 | NVDA已披露股数；当前快照；SEC当前SIC可作粗分类入口 | 股数按公开时间生效，处理拆股；区分报告股数/自由流通股；行业必须带有效期 | 全量自由流通股和历史行业尚缺，可先核现有渠道，必要时用户授权表；不必把GICS授权当唯一选择 |
| P0 | 港股行动、PIT财报、退市池与授权事件 | 港股原始价可用；F10只有报告期，部分政府背景可用 | 补公告时点和独立行动台账，不能把期末当公开日期 | 当前确有授权渠道缺口；用户导入或另取许可。沿用本项目港股不取Yahoo、不自动抓HKEXnews的决定 |

| P1 | 分析师EPS/营收一致预期及修正历史 | 现有Finnhub账户，但本次没有验证完整历史预期端点/额度 | 核现有额度、字段、forecast fiscal period、首次时间及修订；保留每个vintage | 先核现有权益；不够时需要新增授权历史或用户文件，不能用当前评级快照代替修正历史 |
| P1 | 历史期权链、IV曲面、Greeks、OI | CBOE当前延迟链探测/样本；当前项目政策禁默认启用 | 清零IV/过期记录只是第一步，还要同字段历史快照与时间戳 | 历史链及使用资格尚缺，需要授权来源；VIX指数历史不能代替个股期权历史 |
| P1 | 空头余额发布历史与借券成本/利用率 | FINRA双周、RegSHO日文件渠道被探测；没有已登记历史面板 | 采集历史文件并按发布日期生效，区分短卖成交量与空头余额 | FINRA部分属工程缺口；借券费率/利用率/可借量需要另核授权渠道 |
| P1 | 历史新闻正文/公告内容与实体时点 | Finnhub/GDELT/RSS/SEC/IR可提供当前内容入口 | 正文范围许可、实体识别、去重、附件解析、首次公开时间、长期存档 | 当前背景无需换源；历史正文与修订覆盖不足，不能承诺现有免费额度可全补 |
| P1 | 因子收益库与个股历史风险暴露 | FF3与Momentum完整ZIP在本地 | 解析、登记、核单位/版本；使用预测前滚动窗口估计暴露及残差风险 | 可先做自有透明风险层，不必先采购完整Barra成品；不能把研究版称为官方Barra模型 |
| P2 | 13F/Form 4/N-PORT、ETF持仓与资金流 | 申报目录、ETF文件及东财供应商流量样本 | 正文解析、披露滞后、修订、映射；对资金流定义和单位做审计 | SEC可先补工程；完整日频机构持仓/真实基金流往往另需授权历史 |
| P2 | 微观结构、买卖报价/盘口/成交逐笔及交易成本 | 当前或局部分钟/报价样本，已有部分小时行情 | 对齐交易场所、报价时间、价差、冲击、容量 | 没有验证多年同口径逐笔/盘口库；若研究高频或成本模型，需要另补渠道，小时线不能替代 |

当前账户和渠道的“可用”仅指本地证据对应的端点与字段。本次未调用账户，未以旧探测反推今天额度，也未购买或启用新来源。

## 当前可运行的因子范围

美股第一版可在已登记NVDA/SPY数据上运行趋势/反转、波动、回撤、异常成交量、Amihud、对SPY的beta与特异波动等描述。财务层已有NVDA材料，可计算带财务期间和公开时间标记的价值、质量、增长与杠杆；不能把单只股票和ETF做成宽横截面排名，也不能把行业/市值缺失补0后中性化。

宏观当前可作为报告背景；具备历史vintage和发布时点之前不进入历史训练特征。新闻先保留上下文角色；Kronos输出是一个候选模型信号，加入训练时需要历史封存输出或严格按折生成，不能在同一训练标签拟合出的分数上再报告测试增益。

宏观还有独立的系列/映射缺口：7序列库存不含汇率；默认`FX/RATE`占位符尚未映射到实际系列，已有`DFEDTARL/U`不会自动变成`RATE`。这些问题与精确发布时间/历史vintage缺失分开处理，本轮报告已提供逐因子需求表。

七姐妹可以作为下一步小范围面板，但同属少数大盘科技公司、横截面很窄。在此范围内应报告原始与中性化结果、样本数和矩阵秩；行业/市值回归自由度不足时关闭中性化，不把有限信息硬拟合成“纯alpha”。更广股票池和多市场阶段能提高检验范围，但仍需独立历史留出。

## 已保存结果提示的工程问题

`runtime/nvda-full-run/financial/financial-audit.md`已记录旧财务引擎快照的三个问题：最新半年累计现金流未重建到最新季度，CFO/capex TTM停留2026-04-26；利息费用旧标签可停留2024年；长期债可能选中非流动部分而非总额。旁边的`audited_metrics.json`有独立年度+YTD核验组件。多因子接线时应先核对这些口径，不能因为文件已经登记就直接相信所有派生比率。

**本轮已修复上述财务计算并通过独立原载荷对账。** 截止2026-11-05已知的CFO/capex TTM为134.360B/7.354B美元、利息464M美元，窗口2025-07-28—2026-07-26；长期债含流动部分为33.366B美元。营收/净利润/利息的累计链与四季合计各有1M美元差额，输出保留方法、组件和差额。原审计快照保留历史，新证据见[财务独立复核](../runtime/multifactor-v1-integration/independent-review/financial-cashflow-final-review.json)。修复计算不等于补齐历史PIT或新增股票覆盖。

`coverage.csv`的True只表示该短窗口供应商字段描述覆盖；`price-provenance.json`仍明确`eligible_for_training=false`。宏观记录的空`available_at`与日期估计的财务质量也须在因子准入报告中透传，不能被通用补缺逻辑抹去。

## 可以由用户补充的文件/渠道信息

优先提供：历史股票池与退市记录；带`valid_from/valid_to/available_at`的行业分类与股本/流通股；若需要预期因子，再提供带发布日期、预测财年和修订版本的分析师一致预期。港股需要独立行动与公告时间资料。可先说明来源名、字段、历史起止和使用权限，不必在聊天或报告中公开密钥。

完整逐文件路径、SHA、列名、日期与数据量见[机器可读审计](../runtime/multifactor-integration/data-channel-audit.json)；[审计脚本](../runtime/multifactor-integration/audit_channels.py)只读原始数据与登记库，写入审计结果。已有来源边界见[分析数据就绪度](ANALYSIS_DATA_READINESS_2026-11.md)及`stock-data/policies/source-policy.json`。
